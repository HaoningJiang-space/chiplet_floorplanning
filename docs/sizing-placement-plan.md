# 中介层尺寸与芯粒布局联合优化（计划，运行前冻结，2026-11-16）

依据：[问题筛查](problem-screens-plan.md)（面积筛查不退化：6/10 例缩小 15% 时升温 ≥ 3 K 或放不下）；[与前作的区别](sizing-prior-differences.md)；[成本数据](interposer-cost-data.md)。

## 1. 问题

给定异构芯粒（尺寸、功耗、类型）、网表、间距规则、每类芯粒的温度上限和封装技术选项，**同时**决定：
- 中介层的宽 W、高 H 与封装技术选项 o；
- 每个芯粒的位置与朝向。

三个目标：封装成本 C(W, H, o)、最高归一化温度 θ = max_i (T_i − T_max,type(i))、线长 L。输出三者的 Pareto 前沿。

### 1.1 成本模型（只含随中介层变化的部分；芯粒自身成本与布局无关，不计）

- 每片晶圆的中介层数：DPW = π(d/2)²/A − πd/√(2A)，d = 300 mm，A = W·H。
- 中介层良率：Y = (1 + D0·A/c)^(−c) · y_s^(k−1)；k = ⌈A / 858 mm²⌉ 为曝光场数（拼接），y_s 为每条拼接缝的良率。
- 中介层成本：C_int = 晶圆价 / (DPW · Y)。
- 基板成本：0.005 $/mm² × 分档系数 × 基板面积；基板面积取中介层面积的 2 倍（Eris 取均热板为中介层 2 倍，这里同样声明为假设）。
- 默认参数（Chiplet Actuary）：晶圆 $1,937（65 nm 代工价），D0 = 0.06 /cm²，c = 6，y_s = 0.99。
- 技术选项：
  - o1 单片硅中介层：W、H 都放得进一个 26 × 33 mm 曝光场；
  - o2 拼接硅中介层（CoWoS-S 类）：A ≤ 3.3 × 858 ≈ 2,831 mm²（取 TSMC 的 3.3 倍；文献也有约 2,700 的说法，取大者），k ≥ 2；
  - o3 超过 o2 上限：RDL 中介层加局部硅桥（CoWoS-L 类），按 Chiplet Actuary 的 RDL 参数（晶圆 $1,200、D0 = 0.05、c = 3）计，A ≤ 5.5 × 858 = 4,719 mm²；
  - 都放不下记为不可行。
- **敏感性**（论文中报告）：D0 ∈ {0.06, 0.15, 0.3}（ECO-CHIP 范围，α = 3 时另算一组），y_s ∈ {1.0, 0.99, 0.95}，晶圆价 ∈ {500, 1,937}。

### 1.2 温度

- 精确 FV（现有模型）；中介层尺寸变化时，均热板按现有规则（max(100 mm, 长边 + 20 mm)）。
- 每类芯粒的上限：工业案例 GPU/逻辑 95 °C、HBM 85 °C；ATPlace 例子没有芯粒类型，统一一个上限，θ 退化为峰温减上限。
- 散热：ATPlace 例子用现有默认 h；工业案例用已标定的 h（产品排法 GPU 85 °C）。

## 2. 方法（sizing_space）

1. **面积预算**：每例取 6 档 A_b = {0.85, 0.92, 1.0, 1.1, 1.25, 1.5} × 原中介层面积（工业案例为紧中介层面积）。成本是面积的单调函数（光罩阈值处跳变），所以按面积预算扫描就覆盖了成本轴。
2. **形状与布局的整数规划**（每个 A_b）：
   - 在现有相对位置整数规划上，把中介层宽 W 离散为 0.5 mm 一档的一热变量，高 H 为连续变量，约束 H ≤ Σ_l z_l · A_b / W_l、H ≤ H_max；
   - 芯粒边界约束改为 x_i + w_i/2 ≤ W 等（对 W、H 线性）；目标为线长（簇平均下界，同 relation_space）；
   - 在宽度精度内是精确的；用"禁止上一个解的宽度档"的割平面依次求出线长最好的 K = 3 个不同形状。
   - **运行前补充（实现时，2026-11-16）**：长宽比限制在 1:3 到 3:1（否则宽度档会多达数百个、包络尺寸不合理，真实中介层也不会过于细长）；每选定一个形状，同时排除其宽度 ±10% 内的档，使 3 个形状真正不同；每个形状使用该宽度档允许的完整高度 min(H_max, A_b / W_l)，即用满面积预算（缩小只会更热）。
3. **每个形状的热精修**：把形状固定为中介层，运行 relation_space（最短端种子 + topology_slp），温度目标为 θ（每类芯粒的上限）。FV 预算按形状均分。
4. **汇总**：所有（形状、布局）的 (C, θ, L)，取三目标 Pareto 前沿。

需要的代码：成本模块；整数规划中 W、H 变量与宽度档；topology_slp 支持每类芯粒的上限偏移（θ 取代峰温）；sizing_space 方法与实验脚本。每项都有测试，先在小例子上核对整数规划解与穷举一致。

## 3. 实验

**例子**：ATPlace Case1–10（间隙 0）；工业 G1（H100 类）、G2（4 GPU + 16 HBM + 2 IO），间隙 0.2 mm，散热按已标定的 h。

**对比**（同一面积预算、同一 FV 预算）：
- B1 "先定尺寸再布局"：中介层保持原长宽比，面积等于 A_b，用现有 relation_space。它隔离"形状参与优化"的价值。
- B2 ATPlace2.5D：只在原尺寸下有结果（已有），作为单点参照。
- B3 FAPlace：查代码是否公开；不公开则按论文复现，作为后续阶段，复现细节逐条注明。
- B4 TAP-2.5D：需要 CPLEX 许可证，另行安排。

**FV 预算**：每个（例子、面积预算）1,000 次，sizing_space 与 B1 相同；种子 1，单种子。

**指标**：
- 每个面积预算下，sizing_space 与 B1 的前沿按带裕量支配比较（凉 ≥ 1 K 且线长不更长，或短 ≥ 10% 且温度不更高；规则同 ATPlace 比较）；
- 成本—温度曲线：给定 θ ≤ 0（满足所有上限）时的最低成本，两种方法各自报告；
- 光罩阈值：最优解落在 o1、o2、o3 中的哪一个，以及随参数（D0、y_s）是否改变。

## 4. 判定（运行前写定）

- **形状联合优化有效**：在全部（例子、面积预算）组合中，sizing_space 胜 B1 的组合 ≥ 40%，且 B1 胜的 ≤ 10%。
- **无效**：B1 胜 ≥ 25%，或 sizing_space 胜 < 15%。
- 其余为部分有效。
- **光罩决策非退化**：至少 3 个例子在敏感性参数范围内，"满足温度上限的最低成本解"所用的技术选项会随参数改变。否则如实报告光罩阈值在这些例子中不起决定作用。

## 4.1 分析细则（结果出来前补充，2026-11-16）

- 每个（例子、面积预算）：两方各取自己全部布局的 (线长, 峰温) Pareto 前沿，按线长均匀取 16 个，用与 ATPlace 比较相同的 `outcome` 规则判胜负；联合方法的前沿合并了 3 个形状。
- 光罩决策：每例的温度门槛 T_cap 取 B1 在原尺寸（面积倍数 1.0）下的最低峰温。在所有面积预算、两种方法、所有形状中，取峰温 ≤ T_cap 的最低成本解，记录其技术选项（单片、拼接及曝光场数、RDL 加桥）。成本只依赖宽和高，参数扫描不需要重跑：D0 ∈ {0.06, 0.15, 0.3}，y_s ∈ {1.0, 0.99, 0.95}，晶圆价 ∈ {500, 1,937}，共 18 组。某例在 18 组中最低成本解的选项（或曝光场数）至少变化一次，记为"决策随参数改变"。

## 5. 运行前估计

- 芯粒密集、长宽比不合适的例子中，形状选择对线长和温度影响大，预计 sizing_space 在 Case4、5、9 等明显胜出；稀疏例子持平。预测为"有效"或"部分有效"。
- 光罩决策：原面积在 1,764–3,599 mm² 之间，多数在拼接区间内；工业 G2（约 7,600 mm²）超过 5.5 倍光罩，在当前选项下不可行，需要多中介层，这一点会如实报告。

## 6. 局限

成本参数大多是公开估算并做敏感性分析；拼接良率无公开数值；基板面积比例是假设；单种子；ATPlace 例子没有芯粒类型。

## 2026-11-16 第一性原理复核（fcffd7f / b50044e；原冻结记录保留）

[证据](evidence/first-principles-sizing-b50044e.json)与[累计记录](overall-research-status.md)给出以下修正要求。
本节记录已确认的问题，不声称实现已修复，也不追溯改写既定运行的判定规则。

- `Problem` 只保留 `limit_i - min(limit)`，Evaluator 输出 `max(T_i - offset_i)`；
  这是与超温量相差 `min(limit)` 的等价排序分数，不是本计划的 θ，也不是实际峰温。
  需保留绝对温限、实际每芯粒温度、超温量与达标状态，不能把分数当 °C 峰温发布。
- 第 4.1 节的基线最低温门槛属于“匹配基线温度”的相对比较，不能替代第 1.2 节硬温限。
  当前技术判定只保留宽、高、分数，丢弃线长；应在共同互连预算下保留同一布局的完整指标。
- `sizing_compare.verdict` 丢弃 unavailable 后重算分母，与“全部组合”规则不同。
  1 胜 + 59 unavailable 会给出 effective / 100% 胜率；全部 unavailable 会给出 ineffective。
  应保留完整组合数、失败原因和覆盖率，完成前只能给部分结果；未知不能自动算胜或负。
- 成本不是全域面积单调函数：默认模型在 2,831.399 → 2,831.401 mm² 时，
  由 stitched 切换到 rdl_bridge，模型成本约 772.81 → 364.22 USD。
  这不是制造报价验证；它否定了以单调性声称六个面积点覆盖成本轴的理由。
- `option(W,H)` 目前按面积强制归类，不是在同一尺寸上比较多个可用工艺。
  FV 始终使用同一硅中介层配方，没有 RDL/局部桥对应的材料与结构。
  因而当前可解释为固定热模型上的尺寸搜索和成本敏感性，尚非不同物理工艺的联合热优化。
  最小推进路径是先限于现有配方支持的硅中介层；其他工艺暂保留为声明假设的成本情景。
- 两个候选的温度、线长均相同（80 °C、1 m），仅尺寸为 50 × 56 与 50 × 57 mm，
  18 参数组仍使技术选择变化。故“随成本参数变选项”只证明成本敏感性，不能单独证明
  温度推动跨光罩决策。需与相同候选集、相同参数下撤除/放宽温限的选择配对比较。
- 当前输出只存 length_m、peak_c，未存坐标、朝向、每芯粒温度、实际求解次数和代码/输入身份。
  后续运行应复用 run_reference_front 的布局归档；现有缺布局结果只能保留为探索性标量记录。
  不要为弥补记录遗漏默认重跑全部案例，先补归档，再做必要的代表点复核。
