# 布局决策究竟需要知道哪些负载信息？

**一项负载细节可以从布局输入中删去，当且仅当删去它后，每组无法区分的工况仍有至少一个共同合规、足够好的布局。** 因此先找出哪些物理差异能改变选择，再决定负载描述、模型保真度和搜索方向。一个模型可以把绝对温度算偏，但仍选对布局；若还有绝对温限，必须另把温限作为硬约束。

### 如何在新设计上使用

1. **固定要做的决定。** 明确何时锁定芯粒坐标、那时能获得哪些信息。列出硬约束、可行域和损失容限。本次用相同引脚距离上限下的硅层峰温，容限沿用 0.1 K。吞吐率或时序裕量也能单独作为目标，单位和可行性随之改变。
2. **从物理提出最简单的负载描述。** 热问题先保留逐芯粒平均功率，再考虑哪些位置一起改变功率、持续多久。平均功率决定周期平均温场，热容和传热路径决定每次功率波动在热点形成的额外温升。互连问题可先保留跨越容量瓶颈的需求。保留一个量的理由是它可能改变设计间的相对优劣。
3. **主动寻找会被这个描述混淆的工况。** 保持它能看到的量完全相同，只改变被省略的量。对每个工况留下距离、可布线性、温限等约束合规，且距该工况最优值不超过容限的全部布局。该组所有集合的交集给出可用同一设计的范围。仅比较赢家编号会错过平手和折中解，仅检查两两交集也会漏掉三个工况合起来才出现的冲突。
4. **用交集指导下一步设计。** 交集非空时就从中固定一个布局；交集为空且开工前能知道更多负载信息，就增加能拆开冲突工况的那一项，并只在受影响的分组重算。若生产前始终不知道负载，就把相冲突工况的性能要求同时交给布局搜索，找能进入交集的新几何。只有对整个可行空间给出不可行证明，才足以排除所有可能设计。

### 必要充分条件与可计算的判据

令 $s$ 为工况，$g$ 为设计，$F_s$ 为在该工况下可行的设计集合，$J(g,s)$ 为待最小化的物理量。假定每一工况有可行解且基准最优值可得。定义 $J_s^*=\min_{h\in F_s}J(h,s)$，$A_\epsilon(s)=\{g\in F_s:J(g,s)\le J_s^*+\epsilon\}$。给定开工前可获得的描述 $z=D(s)$，一个只使用 $z$ 的确定性决策能在每种工况都达标，当且仅当

$$\forall z\in D(S),\quad \bigcap_{s:D(s)=z} A_\epsilon(s)\ne\varnothing.$$

证明只需要两步。相同描述只能输出同一布局；这个布局要在每种可能工况下达标，就必须在交集中。反过来，每组选一个交集元素就构造出达标的决策。可以不断细分描述，因为原先可用的选择在子组中仍然可用。删除多个量时必须对删除后的分组整体检验。对设计时完全未知且不能条件化的工况，所有工况属于同一组。这个结论不依赖热方程、具体网表、优化器或工况出现概率。这里使用已知的最坏遗憾与信息比较思想，把它落实到物理布局决策。[Blackwell，Comparison of Experiments](https://digicoll.lib.berkeley.edu/record/112749)

若每个预测只有可靠的 $[L_{g,s},U_{g,s}]$，可为任意固定 $g$ 在每条工况上分别计算可证的损失上界 $[U_{g,s}-\min_{h\ne g} L_{h,s}]_+$ 和下界 $[L_{g,s}-\min_{h\ne g} U_{h,s}]_+$，竞争者取该工况下其他可行设计。组内有一布局的最坏上界达标，就可安全删去信息；若每个共同可行布局都在至少一个工况的下界超标，就已得到“不知道该量无法保证达标”的见证；其余情况需收紧区间。若只对候选池计算，基准与结论都相对于该池。静态、瞬态或实测模型的取舍遵循同一原则，模型误差界必须覆盖所声称的工况。用于物理类别的界不能用同模型回放误差代替。[通用计算实现](../src/chiplet_floorplanning/placement/decision.py)

实际用稳态评分替代瞬态评分时，还要核对稳态算法选出的具体布局确实属于交集。交集非空只说明有办法凭这组信息选对，并未给任意简化算法都提供保证。计算交集的开销发生在建立规则时；本轮没有以减少求解时间作为实验结果。

### 移除空间信息与时间信息的实际代价

本地将 360 个已发布的热评价重新分组。表格给出只凭列头信息、允许为每个可区分组分别选一个布局时，最好的这种选法与逐工况最优相比，在最不利工况高出的峰温（K）。每例 6 个活跃芯粒对 × 3 个任务时长，逐芯粒平均功率在 18 种工况之间完全相同。每个网表分别设计。最后一列完整标识这个有限实验的工况，零是枚举基准。

| 网表 | 只知平均功率 | 平均功率＋时长 | 平均功率＋活跃芯粒对 | 两者均知 |
| --- | ---: | ---: | ---: | ---: |
| Case2 | 0 | 0 | 0 | 0 |
| Case3 | 1.673 | 1.673 | 0 | 0 |
| Case4 | 2.675 | 2.675 | 0.916 | 0 |
| Case5 | 3.764 | 3.764 | 0.599 | 0 |

在 0.1 K 容限下，Case2 一个固定布局已经足够。Case3 知道哪两颗芯粒活跃就足够。Case4 的 GPU 对 (1,3)、Case5 的 CPU 对 (0,3) 和 (2,3) 仍需区分时长；另外 21/24 个网表—芯粒对分组均能由上下界给出共同布局。这说明对于这批负载，先辨别热源位置、只对少数分组追问时长，比要求所有负载都提供完整的时序轨迹更有针对性。

按实验前约定冻结的共同布局，用在 15.81 和 158.11 ms 两个新时长。四个案例、五种原几何、六个位置对，新增 240 个本地几何评价，全部逐时域重放。21 个已接受分组形成的 42 组新比较，固定选择全部达到池内最优，分别用新工况上下界也能证明这一点。另六组原规则保留时长信息，没有计入这 42 组的成功次数。若强行对它们也冻结旧选择，观察到的最大损失为 0.149 K。该实验验证同一模型与几何上的新时长，独立封装与测量是另一种外推。[分组、全部未见时长与重放](evidence/workload-information.json)

### 两个不同物理域的检验

**热存储给出有限采样的反例。** 两个互不耦合的热节点取 $R=1$ K/W，$C=0.005,0.05$ J/K，平均温升 5.00、5.65 K，任选一个承受等时 ±1 W 波动。另一个独立参考节点取 0.1 K/W、0.5 J/K、平均功率 3 W，反向补偿波动，故瞬时总功率不变，参考节点温升至多 0.4 K。每个节点在方波半周期 $d$ 的周期温度半摆幅为 $aR\tanh[d/(2RC)]$，这里 $a=1$ W。全系统峰值也计入未脉冲的位置。5、50、500 ms 皆选 A；15.81 ms 却是 B 较凉 0.112 K，超过同一容限。这个解析对照是为检验外推边界而构造的。要保证一整段连续时长，须用覆盖整段的界。例如若该区间的每个候选峰温对时长都有已证的共同 Lipschitz 常数 $K$，同一可行池且任一点离已测时长不超过 $h$，同一个固定布局的最坏损失最多为已测最坏损失 $+2Kh$。因为布局与基准最优峰温最多各变 $Kh$。经验拟合的斜率不构成该保证。

**互连容量给出可以覆盖连续域的正例。** 在四节点、各有向链路容量相同的环上，四个端点的对称流量由三组互配份额决定，三者之和为一。选择一组 $d$ 放在对角，另两组 $a,b$ 走相邻边。单位端点注入率下最紧链路负载为 $d+\max(a,b)$：两个相邻端点组成的两个方向的割分别给出 $d+a$ 和 $d+b$ 的下界，直连流直走、对角流均分到两条两跳路径即可达到。故要最大化吞吐，只需知道哪组份额最小，将它放在对角即可。无需精确流量幅值就能选映射，但计算能交付多少吞吐仍需要幅值。若只知道无标签的份额 (0.45,0.45,0.10)，不同的轻流位置会要求不同映射；在仓库的参数下选错时为 0.535 TB/s，选对为 0.876 TB/s。该推导适用于上述连续对称流量族，去掉等容量环或对称流量假设后应重新做判定。已有 861 组流量、2,583 个映射的独立线性规划核验了公式。[互连实验与求解误差](evidence/cut-traffic-v1.json)

对新的网表，首先要交付的是**哪些负载可以用同一布局，哪些物理差异会迫使设计分开，以及这个判断覆盖的工况范围**。这给出了简化模型的停止条件，也给出了下轮布局搜索应该同时满足哪些矛盾工况。

本轮将完全相同的分组代码用于负吞吐率（单位 TB/s），并在本机重新运行已有的 2,583 个流量线性规划。只知总量，或知道排序后的三个份额却不知道各自对应哪些端点，两种描述的最坏吞吐损失均为 0.482 TB/s。只知最小份额对应哪组匹配，三个信息组的最坏损失均为零。这里能够把离散验证推广到整个连续流量族，依据是割界与可达到该界的路由构造。热实验中相同的代码只能对已覆盖工况给出保证。

## 新时长检验前的约定

本轮全套 202 项测试通过，双芯粒 CLI 校验与评估通过，3 W、34.1886 °C。全部热与互连求解使用本机；两次新增时长求解得到相同结果。

本机 fetch 后与 `origin/main` 同为 `d37529cd3c5a65b4e098507469ef6be7e13660ff`。先复用了已发布的 4 个网表、每例 5 个预算内布局和 18 个负载情景。这里按设计时能知道的负载属性分组，比较只知道逐芯粒平均功率、另知道活动对、另知道时长、两项皆知四种情况。该部分属于对已知结果的重分析。

在计算新的中间时长之前，固定以下迁移实验。每组用原有 5、50、500 ms 的峰温上下界评估能否忽略时长，沿用 0.1 K 容限。对每个网表的每个活动对，选择跨三个时长的最坏损失上界最小的布局，平手取原布局编号。上界不超过容限才输出固定布局，否则保留时长信息。冻结该选择，原样转到两个相邻已知时长的几何平均数（约 15.81 和 158.11 ms）。对四例的全部五种几何、六个活动对在两个新时长本地复算，维持同一平均图、预算、32 档几何贴合网格和每段四个后向欧拉子步。对未选择固定布局的组也保留全部结果。报告可直接迁移的条件数、实际损失、区间是否证实迁移，以及冲突与反例。两个新增时长仅作离散检验。
