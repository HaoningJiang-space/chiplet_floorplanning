## 共同形态

1. **问题**：几乎都是"在布局里加入一个新的物理或制造效应"并称"首个"，或"合并原本分开的步骤"（划分 + 布局、层分配 + 布局）。只靠更好的搜索器的很少。
2. **方法**：新模型或新约束 + 能扩展的求解器（解析/梯度、MILP、拓扑表示 + 退火）。物理模型若是贡献，需报告对标准仿真器的误差与加速比。
3. **证据**：4–10 个例子，最多约 60 个芯粒；TAP-2.5D 几乎必比；线长 5–60%、温度 3–13%、速度 5–20 倍；不少摘要只有定性结论，问题新颖性分量很重。
4. **空白**（调研者推断）：互连都用线长代理；单一稳态工况、冷却固定；前沿只与启发式比，没有最优性差距；单次运行、不报方差。

## 我们的对照

| 要求 | 我们 | 判断 |
| --- | --- | --- |
| 新效应或合并步骤 | 与 ATPlace2.5D 同一问题（线长 + 温度） | 最大缺口 |
| 可扩展求解器 | 整数规划 + 精确热梯度，60 个芯粒可跑 | 够 |
| 模型精度与速度 | FV 与 ATSim 排序一致；未与 HotSpot 比误差与加速 | 部分 |
| 比 TAP-2.5D | 未比（需 CPLEX） | 缺 |
| 改进幅度 | 对 ATPlace 同线长凉 2–14 K、快 4–15 倍 | 够 |

另：上一轮提出的"岸线 + 可达距离"方向，与 Coskun、Kahng 等 TCAD 2020（链路可达距离、µbump 分配与边缘开销、温度、布局联合优化）大部分重叠；EMIB 相邻约束有 ICCAD 2023。
