# R3 验收：合法候选更多，不等于布局质量稳定提高

本阶段验收通过的是**冻结实验的执行、记账和比较方法**；没有验收出一种稳定更优
的算法。NSGA-II 条件合法变异减少了非法候选，但质量收益随案例和约束变化。
不增加种子、不事后修改权重来消除这个负结果。

## 主指标：相同距离预算下是否更凉

下表为 `nsga2_legal` 相对 `nsga2` 的逐种子差值后取中位数。
正数表示降温；距离为需求加权的**平均中心 Manhattan 距离**，不是已布线长度。

| 案例 | 共同 p50 距离预算 mm | 配对降温 K，中位数 [范围] | 胜/平/负 | 双方达到约束 |
| --- | ---: | ---: | ---: | ---: |
| Ascend910 | 31.7516 | 0.0000 [0.0000, 0.0000] | 0/3/0 | 3/3 |
| Micro150 | 32.0000 | +0.3740 [-1.2031, +0.4971] | 2/0/1 | 3/3 |
| MultiGPU | 29.6296 | +0.1499 [-2.6027, +1.5176] | 2/0/1 | 3/3 |

反向比较同样必须保留：在相同 p50 温度上限下，条件变异相对原 NSGA-II 的距离
缩短中位数分别为 **+1.3858%、+8.1218%、-9.9617%**。MultiGPU 三个种子的
距离都变差，范围为 -30.0000% 到 -7.9681%；不能只用正的中位降温宣称全面改善。

三档约束也不是可任选的有利结果。条件变异的 p25/p50/p75 降温中位数分别为：
Ascend **+0.2534 / 0 / -0.1011 K**；Micro **+0.0132 / +0.3740 / +0.3740 K**；
MultiGPU **+1.5176 / +0.1499 / -0.4909 K**。MultiGPU 的 p75 三对全部变差。

TAP-derived SA 相对 NSGA-II 的 p50 降温中位数为 +0.0258 / -1.7126 / -0.8233 K；
Micro 和 MultiGPU 三对全部较差。MultiGPU 的严格 p25 距离预算下，TAP-SA 有一条
未达到约束，只能报告另外两对的条件中位数 -2.0120 K，不能把缺失值当零收益。
这是共同网格、64 查询和声明初始化下的 TAP 坐标策略改编，不代表原论文完整 TAP
流程较弱。三个种子支持描述性结论，不支持显著性或 SOTA 结论。

## 辅助指标：改善的是哪一部分

每栏为三个运行各自数值的中位数；非法比例逐运行计算后取中位数。
Proposal 统计包含共同初始化提交，条件候选枚举另计。

| 案例 | 原 NSGA-II 非法比例 | 条件变异非法比例 | Proposal 原版 → 条件变异 | 条件候选枚举次数 | 过滤时间 s |
| --- | ---: | ---: | ---: | ---: | ---: |
| Ascend910 | 86.31% | 48.55% | 1271 → 138 | 797812 | 0.9931 |
| Micro150 | 79.35% | 51.83% | 489 → 164 | 1015324 | 1.9457 |
| MultiGPU | 86.05% | 44.62% | 1887 → 137 | 691472 | 0.8941 |

交叉仍可能制造相互重叠，条件变异只针对当前单芯粒检查，其后保留完整几何检查。
因此非法比例不会自动降为零。以上数据证明拒绝候选数量下降，也显示为此付出的
枚举工作；不能将它解释成同预算温度一定更好。

本轮条件变异墙钟中位数为 63.28 / 87.79 / 59.40 s，旧 NSGA-II 为
148.16 / 176.25 / 135.94 s。两批运行时间和工作站负载不同，旧热查询直接复用，
这些数值只作成本记录，**不计算受控加速比**。完整 JSON 保留各运行成本和辅助 HV。

## 验收裁决与下一项修改

1. **执行/比较通过**：预定约束、共同初始化、同等热查询预算、完整结局和回放均保留。
2. **算法优势未通过**：合法变异有明确候选生成收益，但没有稳定的双目标质量收益；
   保留为基线组件，不据此宣布新算法成功。
3. **物理范围不扩大**：当前是简化稳态热与中心距离；没有 PAD、实际走线、温度相关
   I/O 功耗或时序闭环。案例与模型的限定验收见 [范围记录](case-physical-acceptance.md)。
4. **下一步只接一个案例**：接通 ATPlace Case1 的真实输入 pin 偏移、四向旋转、
   总 pin Manhattan 长度与热评估；先验证平移/旋转如何改变目标，再进入结构搜索。
   不同时扩大到 61 个芯粒或堆叠新的优化器。论文实验依据见 [对照](paper-experiment-comparison.md)。
