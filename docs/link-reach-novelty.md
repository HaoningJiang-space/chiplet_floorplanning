# 链路可达距离 × 布局 × 温度：新颖性核查与可行性检查（2026-11-15）

## 动机

[自热/互热分解](overall-research-status.md)显示，布局对温度是一阶旋钮：互热占最热芯粒温升的 31–76%。
但前面的温度类旋钮都不改变"把高功耗芯粒分开"这一最优结构，所以布局要么与旋钮可分，要么收益只有 1–2 K。
要找新问题，需要一个由布局一阶决定、并且与散热冲突的量。

现有热感知布局（TAP-2.5D、ATPlace、SP-CP、MaskPlace2.5D 等）都把互连代价当作线长，即线性代理。
而芯粒间链路的能耗、带宽和可行性随长度强烈非线性变化，而且分档：
不同封装与物理层有不同的可达距离，超过就必须换档或加中继。

## 校准数据（公开来源）

| 量 | 值 | 来源与性质 |
| --- | --- | --- |
| UCIe 可达距离 | 先进封装约 2 mm；标准封装约 25 mm | UCIe 联盟 Hot Chips 2023 教程；已记录在[基准来源筛查](benchmark-source-screening.md)，2 mm 是某档配置的条件，不是硬物理门槛 |
| UCIe 凸点间距、带宽密度 | 先进 25–55 µm、165–1317 GB/s/mm；标准 100–130 µm、28–224 GB/s/mm | 二手汇总（HOTI 2025 报告），需对照规范原文 |
| UCIe 每比特能耗 | 先进约 0.25–0.3 pJ/bit；标准约 0.5 pJ/bit | 二手汇总（Synopsys 等），随工艺变化 |
| 封装技术的最大链路长度 | 有机基板 10–25 mm（双端端接可到 50 mm）；硅桥、无源中介层 2–4 mm；有源中介层不限 | PlaceIT（arXiv 2502.01449）表 I，注明取决于速率与凸点间距 |
| 能耗随长度变化 | 硅中介层与有机基板的能耗曲线约在 10 mm 交叉；25 mm 时有机 0.41 vs 硅 0.83 pJ/bit（16 nm）。硅中介层发送端能耗：2 mm 0.8 fJ/bit，9.5 mm 28 fJ/bit，20 mm 234 fJ/bit | CLIPGen（arXiv 2605.27757）模型，48 Gb/s/lane，以 ISSCC 2026 一个 30 mm 标准封装实测点校准（文中未给数值误差） |
| 实测短距离硅中介层 PHY | 0.41 pJ/bit，2.35 mm，6.4 Gb/s，28 nm | ScienceDirect 2024 |

结论：能耗与可行性随长度的变化跨一到两个数量级，并在 2–4 mm（硅）与 10–25 mm（有机）处分档。
现有热感知布局使用的线性线长代理在这个范围内会严重失真。

## 新颖性核查

| 工作 | 布局 | 链路长度模型 | 链路技术是否为变量 | 温度 |
| --- | --- | --- | --- | --- |
| TAP-2.5D、ATPlace2.5D、SP-CP、MaskPlace2.5D、DiffChip | 是 | 线长（线性） | 否 | 是 |
| PlaceIT（ETH/Bologna 2025，开源 spcl/placeit） | 是，并由布局推出拓扑 | 单一最大长度（如 3 mm），超过不连 | 否，全系统统一封装 | 否（只建议事后用 TAP-2.5D 微调） |
| Hetero-IF（Feng、Xiang、Ma，MICRO 2023） | 否 | — | 每个芯粒同时用并行与串行两种接口 | 否 |
| CLIPGen（2026） | 否 | 长度 → 能耗/延迟模型 | 发送/接收尺寸 | 否 |
| ThermoDSE（arXiv 2607.07096） | 架构级划分 | 固定 1.17 pJ/bit | 否 | 是 |
| LUCIE（MICRO 2024） | 中介层设计框架 | 未读全文 | 未确认 | 未确认 |

**初步结论**：没有找到同时满足以下三点的工作：
1. 布局决定每条链路的长度；
2. 每条链路按长度选择物理层或封装档（或者长度决定能耗与带宽的分档代价）；
3. 与温度联合优化。

PlaceIT 最接近，但它没有温度，长度上限是单一阈值。LUCIE 尚需读全文确认。

## 可行性检查：前沿布局的网络长度落在哪一档

证据：一次性脚本，在 eex005 读冻结前沿。长度为源 pin 间曼哈顿距离，不是走线长度。

| 例 | 最短布局：≤2 / ≤4 / ≤10 mm 的网络占比 | 上限内最冷 | 全局最冷布局 | 全局最冷布局的网络长度中位数 |
| --- | --- | --- | --- | --- |
| Case1 | 43 / 72 / 89% | 46 / 67 / 78% | 16 / 25 / 44% | 16.9 mm |
| Case2 | 20 / 40 / 85% | 15 / 40 / 78% | 0 / 0 / 0% | 51.4 mm |
| Case3 | 35 / 66 / 96% | 25 / 58 / 87% | 0 / 4 / 35% | 13.7 mm |
| Case4 | 35 / 50 / 56% | 33 / 50 / 50% | 0 / 0 / 20% | 20.5 mm |
| Case6 | 3 / 19 / 79% | 2 / 13 / 74% | 0 / 0 / 2% | 23.5 mm |
| Case9 | 4 / 14 / 56% | 1 / 8 / 41% | 1 / 2 / 9% | 33.4 mm |

散热越好的布局，网络越被推出短距离档：全局最冷布局几乎没有 ≤ 4 mm 的网络，中位数 14–51 mm，部分超过有机基板 25 mm 的可达距离。
所以在线性代理下看似平滑的"线长换温度"，换成分档代价后会变成阶跃：跨过 2–4 mm 或 10–25 mm 时，代价跳一个数量级，或者链路直接不可行。

**限定**：
- ATPlace 的 pin 是逻辑 pin，不是 PHY 凸点。真实设计中 PHY 位于芯粒边缘，两颗相邻芯粒的 PHY 间距可以远小于这里的 pin 距离。
- 所以上表只说明"散热把芯粒推远"的量级，不能直接当作链路长度。正式实验需要把每个网络映射到边缘 PHY，并用有出处的长度—能耗/带宽曲线计价。
