# 接收端 setup/hold 扣除：在已有三布局时序链上补上物理裕量（计划，运行前冻结）

## 问题

[三布局 Xyce 实验](xyce-three-layout-results.md)报告的是可用窗口 W，没有扣除接收触发器
`sky130_fd_sc_hd__dfxtp_1` 的 setup/hold，不能称为裕量。本步只在同一组布局、路径和波形上，
扣除接收器在**自身局部温度**和**实际输入斜率**下的约束，回答两个问题：

1. 扣除后，三对布局的冷/热排序及热交互判定是否改变；
2. 约束随温度的变化相对热交互 I_T 有多大。

不改时钟周期、不加路径、不换设计；Basilisk/IHP 真实接口仍是后续工作。

`whole_hot_deck_contract_passed` 字段，原证据可能由更晚的审计工具生成；数值仍在上述误差内。

## 第一性原理估计（运行前）

开源 Liberty 给出同一工艺与电压（tt，1.8 V）在 25 °C 与 100 °C 的约束表，二者只差温度。
以 setup（D 下降）为例，D 斜率 0.01→1.5 ns 时约束 0.103→0.621 ns（25 °C），
0.094→0.525 ns（100 °C），温度灵敏度约 −0.13 至 −1.3 ps/K。

- 冷（25 °C 均匀）→热（rot180 接收器 64.8 °C）：约束变化估计 −5 至 −50 ps，与已测 I_T（±6 ps）同量级或更大，
  所以扣除约束可能明显改变"热反馈对单个布局裕量"的量。
- 布局之间：同为热态时接收器温度相差约 1 K 量级，差分约束变化估计 ≤ ~1.3 ps，
  小于已测最小布局对差距 2.54 ps，预期排序不变——这是预测，由下面的计算检验。

## 方法（冻结）

1. **测量**：从已复现的冷/热 Xyce 波形（两个时间步）读取每个接收器的 D 与 CLK 的 20–80% 斜率
   （Liberty `slew_lower/upper_threshold` 20/80，`slew_derate` 1.0）和 50% 交叉时刻，局部温度取热态报告中该接收器的值。
2. **约束**：Liberty `setup_rising`/`hold_rising`，`index_1` = CLK 斜率，`index_2` = D 斜率；
   斜率上双线性插值，温度上在 25/100 °C 两表间线性插值；任何斜率或温度超出表范围即失败，不外推。
   D 上升用 `rise_constraint`，下降用 `fall_constraint`。
3. **裕量**：S_setup = W_setup − t_setup，S_hold = W_hold − t_hold；本设计无时钟不确定度，U = 0（如实声明）。
4. **判定**：对布局差 D 与交互 I_T 使用原实验同一冻结筛查（两步同号且幅值大于
   max(步长变化, 控制项 × 均匀对照差异)），分别报告扣除前后的 stable/changed/unresolved 计数与最小窗口排序。
5. **晶体管级核对（门槛在看到结果前写定）**：单个 dfxtp_1，ngspice 全局 `.temp`
   （单器件均匀温度，ngspice 可用），在实测中位斜率下于 25/62.5/100 °C 用二分法求 setup/hold，
   判据：Q 正确捕获且 clock-to-Q 不超过参考值（数据提前 2 ns）的 110%。
   - 门槛：25 与 100 °C 下与 Liberty 之差 ≤ max(15 ps, 25%) 即"一致"；62.5 °C 结果与线性插值之差单独报告。
   - 若不一致：结论仍用 Liberty，并把判据差异作为未解决的模型不确定性报告；不调判据去凑门槛。

## 结果（2026-11-15，eex005，按上述冻结方法执行）

证据：[receiver-constraint-three-layout.json](evidence/receiver-constraint-three-layout.json)
（逐路径斜率、温度、约束、窗口/裕量、判定；晶体管级门槛；复现与原证据的差异）。

**测量范围**：D 斜率 0.065–0.389 ns，CLK 斜率 0.055–0.057 ns，均在 Liberty 表内；
接收器温度冷态 25 °C，热态 64.60–64.94 °C。窗口 9.86–10.14 ns，扣除后裕量 9.74–10.23 ns。

**问题 1：判定是否改变。**

| 布局对 | 冷/热排序（窗口 → 裕量） | 热交互（窗口 → 裕量） | 窗口与裕量的布局优劣异号 |
| --- | --- | --- | --- |
| rot180–rot90 | 32/32 stable → 32/32 stable | 30 → 30 | 2 条路径（冷、热均异号） |
| rot180–rot270 | 32/32 → 32/32 | 32 → 32 | 0 |
| rot90–rot270 | 32/32 → 32/32 | 32 → 32 | 0 |

冻结筛查下没有任何判定改变。但筛查只比较冷与热是否同号，不比较扣除前后：
rot180–rot90 的最差 hold，按窗口 rot90 好 8.78 ps，按裕量 rot180 好 0.92 ps（冷 −0.92、热 −0.90）。
0.9 ps 远小于下文 Liberty 与晶体管级之间 3–29 ps 的差异，**这一对的最差 hold 优劣实际不可判定**。
最差 setup 及另两对的最小值排序方向不变（布局差 33.8–107 ps）。

**问题 2：约束热变化相对 I_T 多大。**

- 冷→热约束变化 −5.33 至 +4.93 ps（setup 变小，hold 变大），是窗口热变化（±10–12 ps）的约 30–45%；
  setup 上升沿与窗口变化同向叠加，setup 下降沿部分抵消。
- 约束对热交互的修正（I_T 裕量 − I_T 窗口）最大 ±3.3 ps，与 |I_T| 本身（0.09–5.8 ps）同量级。

**与运行前估计的对照（两处估计错误，如实记录）。**

1. 约束热变化估计 −5 至 −50 ps，实测只在下端。估计用了整张表的灵敏度；实际灵敏度随 D 斜率增大，
   实测斜率位于表的快端（约 0.1 ps/K），40 K 温升只给 4–5 ps；hold 符号相反。
2. 布局间约束差估计 ≤ ~1.3 ps，实测同一路径在不同布局下差 ±25–42 ps，冷态同样大。
   估计只考虑了温度，漏掉了**斜率**：不同布线给出不同 D 斜率，约束对斜率很敏感。
   所以扣除约束改变的主要是布局之间的比较，而不是热反馈本身。

**晶体管级门槛（实测中位斜率 D 0.1486 ns、CLK 0.0562 ns，二分容差 1 ps）：通过。**

| 弧 | 25 °C SPICE / Liberty（差） | 100 °C SPICE / Liberty（差） | 25→100 °C 变化 SPICE / Liberty |
| --- | --- | --- | --- |
| setup 上升 | 60.5 / 76.3（−15.7，门槛 19.1） | 61.3 / 76.5（−15.3） | +0.7 / +0.3 ps |
| setup 下降 | 124.3 / 153.4（−29.1，门槛 38.3） | 115.5 / 137.3（−21.8） | −8.8 / −16.1 ps |
| hold 上升 | −44.9 / −51.5（+6.5，门槛 15） | −44.9 / −51.9（+6.9） | 0.0 / −0.4 ps |
| hold 下降 | −86.7 / −94.2（+7.6，门槛 23.6） | −77.9 / −80.7（+2.8） | +8.8 / +13.6 ps |

62.5 °C 与 SPICE 25/100 °C 线性插值之差 0–0.37 ps（在二分分辨率内），温度插值成立。
审查（`22ab488`）指出判据未拒绝 NaN、且把首次交叉当作输出时间；修正后（拒绝非有限波形、取最后一次进入期望电平的交叉）
在 eex005 上重跑三个温度，12 个参考 clock-to-Q、setup、hold 值与上表逐位相同，已发表门槛结果不受影响。
结论按计划仍用 Liberty。但下降沿弧的约束温度变化，晶体管级只有 Liberty 的约 55–65%，
所以上面的约束热变化可能偏大约 1.5–1.8 倍；这是判据不同（本工具 110% clock-to-Q 推出）
还是表本身所致，未分辨，作为模型不确定性保留。

**物理意义的边界。** 本设计 10 ns 量级的裕量下，热与布局效应都只有几 ps（约 0.1%），
没有任何路径接近失败。本结果只说明"扣除约束后排序结论的稳健性"，不说明热会改变时序收敛；
回答后者需要把时钟收紧到最差裕量接近 0 的新设计点，另行冻结计划。
