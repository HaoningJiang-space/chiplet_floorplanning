# 散热强度扫描：布局何时对温度重要（计划，运行前冻结）

依据：[工业案例](industrial-cases-plan.md)发现，散热标定到 GPU 85 °C（h 7,000–34,000 W/m²K）后，前沿最凉布局只比最短布局凉 0.5–4.4 K；ATPlace 基准用默认 h ≈ 2,780 W/m²K，同线长下差 2–14 K。猜想：**布局的热收益随散热增强而缩小。**

## 设定

- 案例：ATPlace Case1–10（relation_space 种子 2 的前沿，rs-grb-v4，间隙 0），工业 G1 松、G2 松（industrial-v1，间隙 0.2 mm）。
- 散热器顶面 h ∈ {500, 1,500, 5,000, 15,000, 50,000} W/m²K：约对应风冷到液冷冷板。其余层叠不变。
- 每个 h 下，用 FV 重新求该例**全部前沿布局**的峰温，不重新优化。

## 指标（每例、每个 h）

- T_s：前沿最短布局的峰温；
- **热收益** ΔT = T_s − 前沿最凉布局的峰温（K）；
- **相对收益** ΔT / (T_s − 45 °C)；
- 线长 ≤ 1.25 倍最短线长时的收益 ΔT_1.25。

因为前沿是在默认 h 下优化的，其他 h 下的真实前沿可能更好，所以这里的收益是**下限**。

## 判定（运行前写定）

- **猜想成立**：12 例中至少 10 例，h = 50,000 时的 ΔT 小于 h = 1,500 时的一半。
- **不成立**：至少 4 例 h = 50,000 时的 ΔT 不小于 h = 1,500 时的 ΔT。
- 其余为部分成立。

## 运行前估计

强散热时热量直接向上导出，横向互热变弱，ΔT 应随 h 单调下降；相对收益也下降。预测"成立"。

## 局限

- 前沿只在默认 h 下优化；单种子；
- 只改了顶面 h，没有改层叠，例如更薄的 TIM 或均热板。
