# 整数规划中欧氏距离的多方向投影表示：验证计划（运行前冻结，2026-11-17）

依据：[叠加模型验证](superposition-model-plan.md) 的三模型对照。欧氏代理在同一线长预算内的选点损失 ≤ 0.51 K，
而 MILP 实际使用的轴向包络达到 2.61 K（Case3）、2.10 K（Case9）、1.48 K（Case1）。损失来自距离在 MILP 中的表示，而非代理本身。

## 表示

每对至少一颗有功耗的芯粒 (i, j)，取 K 个均匀方向 u_k = (cos 2πk/K, sin 2πk/K)，独热变量 w_ijk：
- ρ_ij ≤ u_k · (c_j − c_i) + M (1 − w_ijk)，Σ_k w_ijk = 1；
- τ_ij ≥ g 的切线（与现有代码相同）。

固定布局时，MILP 能取到的最大 ρ 是 max_k u_k·d，记为 ρ_K(d)。由多边形支撑函数的性质：
- ||d|| cos(π/K) ≤ ρ_K(d) ≤ ||d||；
- 所以 ρ_K 是欧氏距离的下界，g(ρ_K) ≥ g(||d||)。MILP 温度对欧氏代理是保守的（切线近似带来的微小低估除外）；
- K = 8 时距离最多低估 7.6%，K = 16 时为 1.9%；
- 原有相对关系变量保持不变，仍保证不重叠。

## 验证（全部用已有数据，不新增布局 FV）

数据与 [叠加模型验证](superposition-model-plan.md) 相同：7 例 × 40 个布局，以及已存的 FV 峰温。
对 K ∈ {8, 16}，在固定布局上计算 MILP 可达的最小值（`ThermalProxy.polygon_value`），与欧氏代理、轴向包络并列报告：
- 前沿预算内最大选点后悔值；
- 前沿与随机子集的 Spearman；
- 扣除偏差后最大残差；
- 相对欧氏代理的偏移范围。

## 通过门槛（运行前写定）

取通过的最小 K：
- 7 例中每例前沿预算内最大后悔值 ≤ 0.6 K（欧氏代理本身最大 0.51 K）；
- 每例前沿 Spearman ≥ 0.98。

若 K = 16 也不通过，则不进入 MILP，先查明原因。

本验证只回答"表示是否保留了欧氏代理的选点能力"。MILP 的求解时间（每对新增 K 个二元变量）在第二步单独测量，届时另立门槛。
FV 认证保持不变。

## 运行前估计

K = 8 应已接近欧氏代理：距离低估 ≤ 7.6%，近场切线范围内 g 的相对变化小。预计 K = 8 通过，Case5 的后悔值仍约 0.5 K。
