# Case1：热等价朝向修复与 B/D 局部候选对照

本次确认了低成本朝向修复的距离收益，但**没有额外降温收益**。两组在相同距离预算下
达到同一个物理位置的 103.515212°C，比共同热启动最好点降温 0.197059 K。
修复组该点的距离为 36.805343 m，控制组为 71.188956 m；反向指标改善 6.418%。
这是单种子、25 个固定邻域候选的有界局部结果，不是全局最优或稳定算法优势。

## 第一项验收：朝向与温度解耦

| 共同起点 | 峰温 °C | 实际 pin 距离 m |
| --- | ---: | ---: |
| B 原始 | 103.712271 | 72.596956 |
| B 修复 | 103.712271 | 38.228435 |
| D 原始 | 104.840882 | 58.905473 |
| D 修复 | 104.840882 | 53.427681 |

每次修复仅做一次源顺序扫描，13 次完整 pin 计算，无新热查询。正方形四向转动、
矩形仅半转，逐芯粒命名物理边界完全不变；均匀功率和各向同性材料因此保持热问题。
源 pins 随芯粒刚体转动，距离仍重新计算，最终必要容量检查仍重新执行。
四个起点全部通过必要布线检查。原始响应经精确输入身份核对；修复温度使用明确
限定的物理等价复用，不把不同朝向的 JSON 输入 hash 冒充同一个完整输入。

该算子是当前模型的低成本方向优化，不是温度优化，也不是对非均匀功率图的通用缓存。
本地实际矩阵、功率向量和边界向量不变测试通过；新实验的 13 个重复几何热查询
也得到相同响应。无需为纯朝向试验重复花费热求解预算。

## 第二项验收：固定预算下的实际联合点

固定 L0=73.840208806 m、T0=107.45047721858577°C，未事后调整阈值。

| 选择规则 | 控制组：T °C / L m | 修复组：T °C / L m | 有限结论 |
| --- | ---: | ---: | --- |
| min T，L≤L0 | **103.515212 / 71.188956** | **103.515212 / 36.805343** | 峰温相同；同一热几何的 pin 距离减少 48.299% |
| min L，T≤T0 | **103.712271 / 38.228435** | **104.877521 / 35.775123** | 距离减少 2.453312 m（6.418%），温度升高但仍满足冻结 T0 |

主指标两组均选 B 的 `GPU_1 centre_x_um -2000`：中心从 (23,33) mm 到 (21,33) mm。
修复组主点相对共同 B 修复起点同时降温 0.197059 K、距离缩短 1.423092 m。
这次降温来自候选位置变化，两组都找到了它，不能归功于修复组独有优势。
反向指标修复组选择 B 的 `GPU_1 centre_y_um -2000`，即 (23,31) mm，
与主点不是同一布局。不能把 103.515212°C 和 35.775123 m 拼成一个不存在的点。
完整坐标、朝向、实际输入身份和响应保留在证据中。

控制组全池 21/25 满足 L0，修复组 25/25；两组全池必要容量通过均为 25/25。
按共同顺序，控制组 4 个被 L0 拒绝、5 个因热预算未评估；修复组 9 个因预算未评估。
可行候选增加没有带来本次额外降温。选中结果不证明未查询候选更差。

## 成本与验证

| 成本 | 控制组 | 修复组 |
| --- | ---: | ---: |
| 新热查询 | 16 | 16 |
| 候选 pin 计算（含预算外候选） | 25 | 325 |
| 候选必要布线检查 | 25 | 25 |
| 候选准备时间 s | 1.140 | 8.829 |
| 热评估及记账时间 s | 7.013 | 6.814 |

共同热启动另计 28 次 pin 计算、4 次必要布线检查、约 0.779 s，0 次新热查询。
冻结验收与事后回放的 pins 属于验证开销，不并入算法开销。修复增加 300 次候选 pin
计算；本次热求解很快，不能把减少潜在热查询直接等同于总体加速。

370 项本地测试和两芯粒 CLI 通过，热执行前已经完成。32 条实际热输入身份、
物理设计签名、数值准入、候选/状态/成本/两项赢家全部通过保存响应回放，回放未新增
热求解。最大能量平衡误差 3.781e-7 W，最大原矩阵相对残差 1.011e-10，
同矩阵参考解最大差 2.527e-8 K。这是数值证据，不是目标封装的测量校准。

## 本阶段裁决

保留朝向修复，作为当前均匀芯粒模型中把引脚方向与位置搜索分开的算子；接受它的
距离改善和这次主指标温度持平。暂不增加种子、移动步长或其他算子。
后续若继续，应单独研究如何利用释放的距离余量生成更冷的位置，而非继续依赖朝向
修复降温；仍需公平的共同起点和实际热响应，不用引脚距离代替温度。
详细路由、RC/时序和真实封装校准仍在当前实验范围之外。
