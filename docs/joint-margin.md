## 一个方程让所有芯粒一起选

给每颗芯粒 $i$ 一组位置 $s$（含原地）。用 $z_{is}$ 表示选择哪个位置，每颗恰选一个。在冷板条件 $b$ 的位置 $x$，旧峰温减旧温度是可用余量 $h_b(x)$。把芯粒从原地移至 $s$ 的带符号温差记作 $u_{is,b}(x)$，在原地该值为零。在固定功率、固定导热算子和稳态线性导热下，移动后的温差等于各芯粒温差之和。于是可以用同一个目标选全部位置：

$$\max_{z,g} g,\qquad g+\sum_{i,s} z_{is}u_{is,b}(x)\le h_b(x)\quad\text{对每个 } b,x.$$

可行解还须满足最终脚印不重叠、封装间隙和整个网表的互连成本上限。如果最多可搬 $K$ 颗，只需限制离开原地的选择数不超过 $K$。在所有网格点写下这些约束，$g$ 就是四种边界中最小的真实峰温降幅。先用一部分点求解会给出乐观上界。把提案放回整板，若新的热点突破预测，就加入该处的约束并重新联立求解。每个提案都从原始布局计算。固定某颗先移、沿着上一次坐标挪一步、逐颗接受移动，都不是求解这套方程的必要条件。

双移动实验按与旧法相同的规则要求两颗都平移，再与原地选项比较。位置块只是加速数据结构。对一对位置块 $A,B$，让每个观察点分别取两块中最大的降温贡献，得到该块组合的乐观上界；一个真实组合必须在所有观察点使用同样的两个位置。无法超越当前最佳观测评分的整块可以跳过，保留块内仍精确比较位置、面积间隙和两芯粒共用链路的真实相对位移。两种芯粒都没有首选落点限制。小型双移动问题同时用逐对列举和整数规划核对前三个提案及其成本。[双移动求解](../src/chiplet_floorplanning/placement/joint_margin.py)

允许所有芯粒同时参与时，每个可选落点对应一个整数变量。模型排除互相冲突的脚印。若某组位置超过实际互连上限，利用源引脚曼哈顿距离之和的凸性，加入该点的支撑平面，排除这一类超预算布局。整数求解的对偶上界和整板实得的降温之间的差距决定是否可证明停止。这里所有实验都沿用旧法的静态可放格点，芯粒不能占用其他芯粒在起点占据的位置。[多芯粒整数求解](../src/chiplet_floorplanning/placement/joint_assignment.py)

## 允许所有芯粒决定是否移动

在 Case5 上，放宽到最多 8 次联合核验，强制恰选两颗时，整数求解在第 2 次核验后证明 0.10029 K 是当前离散域内的最大薄板降温。允许 12 颗各自选原地或落点时，求解在 4 次核验后证明可降 0.21483 K，选中 CPU2_3、CPU2_4、CPU2_5、DRAM_1、DRAM_3、DRAM_5，互连为 169.303 m，上限 170.488 m。三维四向最差结果却从两颗的降温 0.183 K 变为六颗的升温 0.060 K。即使薄板上的最优性已经证明，也应当复算最终布局在另一种热路中的表现。

在留出的 3×4 mesh 上，面对同一张引脚网表、同一组可放位置和同一 0.45904 m 上限，允许所有芯粒一起选，四次核验后得到移动 12 颗的布局，互连 0.40604 m。四向最差薄板峰温下降 0.47550 K，三维四向最差下降 0.60218 K，留出的中心边界下降 0.64914 K。最多两颗时相同四次核验返回原地。这是一个在新网表上可复算的多颗协同实例。四次核验尚未证明该布局是全域最优。第二张留出网表只参加双移动主比较。

留出 mesh 的补充冷启动计时从同一份已解析输入开始，分别重建模型、观测、搜索及核验。三轮轮换顺序的中位数为旧法 0.109 s、稀疏双移动 0.145 s、全体共同选位置 10.130 s，三法都是 4 次核验。全体方案三轮均得到同一降温且离散子问题均完成。当前全体求解付出了明显的计算代价。[逐轮时间和解](evidence/joint-margin/all-die-timing.json)

## 普适性补充对照（结果前约定）

在相同载板、相同 4 颗 8 mm 方形芯粒、相同 2×4 槽位与冷板上，使用链、环、星三张合成网表，均匀功率和 0.4、0.8、1.2、1.6 倍异构功率各一组，总功率均为 8.2 W。以种子 20261119 给棋盘交错占用的四个槽位分配芯粒，每颗可原地或直接落在任意一个起初空闲的槽位。各网表的线长上限固定为自身起点总长度，保持足印、间隙和方向；线长采用中心引脚曼哈顿距离。先建立各脚印每瓦响应，再用其重建所有 625 种组合的场，排除重叠和超预算。逐例对比最多 1、2、3、4 颗可动的离散真值，另比较只相加各单移峰温降幅的方案，找出对称性、拓扑和热边界带来的反例。每工况固定直接复算 4 个不同合法终点（优先覆盖不同颗数的最优点）；用封装模型核对最终四向解。这是对物理命题的受控检验，和前述留出测试分别报告。

## 功率、拓扑和边界各起什么作用

在固定线性热路下，芯粒从起点到终点造成的温差是功率乘以该位置对两个脚印的每瓦响应之差。单位为 W × K/W = K。对这组规定功率的实验，换网表只改变可行布局，换功率改变每个脚印的权重，移动冷板则改变每瓦响应本身。对一个给定的目标降幅，每个旧热点都必须得到足够冷却；其他每个位置的净升温也必须留在其温度余量以内。两条要求合在一起正是上述余量不等式。同时满足它们是必要且充分的，前提是覆盖模型中的全部位置与指定边界。

四芯粒实验中，8 个物理槽位乘 4 个边界只需建立 32 张每瓦响应。625 个离散指派中 209 个几何合法；再按各起点的引脚互连上限筛选，链、环、星分别剩 136、159、144 个。求各自整板峰温后，按预先约定每个工况再直接复算 4 个不同坐标、4 个边界，24 次布局复算的最大差约为 3.2×10⁻¹⁵ K。同热路的这个误差只验证叠加计算。[六个工况及全部互连拐点](evidence/joint-margin/transfer-controls.json)

| 功率分布（同为 8.2 W） | 单独移动两颗各自的最差降温 K | 允许 1 / 2 / 3 / 4 颗的最优降温 K | 三维四向最差降温 K |
|---|---|---|---:|
| 均匀 | −0.073、−0.073 | 0 / 0.497 / 0.497 / 0.497 | 0.528 |
| 异构 | −0.059、−0.117 | 0 / 0.751 / 0.751 / 0.751 | 0.735 |

在原点线长上限下，上表在三张网表上相同。两颗芯粒从左右两端各向内平移 13 mm，各自单移都让最差边界更热，联移后留下同一个四向更冷的终点。把各颗的标量降温相加，会在六组全部选原地。放宽允许移动的最大颗数必然扩大可行域，本例从两颗到四颗的最优降温保持不变。留出 mesh 却提供了双移动域确实不足的实例。允许所有芯粒参与并不预先规定有几颗必须离开原地。

两类反例限制了口诀的适用范围。均匀功率下，按西侧冷板单独求出的最优布局在西侧降 2.966 K，换到东侧却升 2.556 K。对全部已计算的可达线长拐点再做事后比较：同是 39 mm 的预算，链形网表可降 0.497 K，星形即使选其最优布局仍升 0.990 K，达到 52 mm 才能实现这 0.497 K。39 mm 比起点的 78 mm 低，因而不能把原地列作可行保底。实验刻意共用热几何；六个组合只代表两个热条件和三种图约束。

ICCAD 2024 的 ATPlace2.5D 把热与互连的布局决策同 TAP-2.5D 比较，报告峰温、线长、规模与运行时间，并展示了超过 60 颗的案例。近期 Chiplet3D 预印本把卷积热场嵌入整数规划，追踪真实引脚、允许旋转翻转，并用 3D-ICE 复算纵向双层设计。两者的几何自由度、封装与本研究有差异，论文的改善百分比不能直接填进本项目的对照表。[ATPlace2.5D 原文](https://yibolin.com/publications/papers/PLACE_ICCAD2024_Wang.pdf) · [Chiplet3D 作者预印本](https://arxiv.org/abs/2607.09742)

本阶段判断：最有希望的算法贡献是利用少量热点约束给出可证的剩余改善上界，直接生成受互连限制的多芯粒协同布局，量化省略观测、模型改变和求解时间的代价。线性叠加本身已是已知物理关系。当前主对照还是仓库上一版，全部 15 例降温增量中位数为零，全体求解只在两例运行。投稿前最有区分力的实验是在同一组公开网表、同一上限和统一三维评价器下，对外部解析布局方法和预算匹配的直接搜索报告峰温、达标所需互连、整板次数、端到端时间及未达标案例；再测全体求解从十几颗到几十颗时的时间和剩余最优性缺口。现有证据支持设定研究问题，尚不能判断录取概率或声称胜过公开方法。

已核对 ATPlace 作者的公开实现 `fe3dbfd`。入口支持线长与热感知两种模式，默认从自身的整数规划起点开始，热版本使用 ATSim 取代原论文中的 HotSpot。严格的对照需要区分两项成绩：从其导出坐标起步，比较同预算可增加多少降温；以及从各自原生起点独立运行，计入启动、训练和合法化时间后比较最终峰温与线长。[作者的固定版本说明](https://github.com/PKU-IDEA/ATPlace_pub/blob/fe3dbfdaf78dc0ddeac3a2cfc3a85ff0971f88df/README.md)

## 本地复现

使用与上一版相同的 ATPlace 导入目录与 TAP 冻结起点，附带的两张新网表可以直接读取。按上游 Git 版本重新生成它们时，运行 `python tools/import_margin_holdouts.py <RapidChiplet-checkout> <output.json>`。开发阶段冻结的搜索代码、温度门槛和网表在揭晓后均未调整。首次三维复算只修正了导出时的案例标识（连字符改为下划线）和 RapidChiplet 来源标签。[旧案例与导入方式](direct-relocation.md#本地复现)

设置 `PYTHONPATH=src`、`OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1`，用 `CASES` 指向 ATPlace 导入目录、`OUT` 指向结果目录。

```bash
python tools/solve_joint_margin.py --cases "$CASES" --repeat 3 --output "$OUT/search.json"
python tools/solve_joint_margin.py --cases "$CASES" --audit "$OUT/search.json" --output "$OUT/audit.json"
python tools/time_all_die_margin.py --cases "$CASES" --output "$OUT/all-die-timing.json"
python tools/test_margin_transfer.py --output "$OUT/transfer-controls.json"
```

本地全套发现的 215 项通过，新加入的分数脚印积分核对与离散三种求解对照也分别通过。双芯粒 CLI 复现 2 条链路、3 W、34.1886 °C。所有实验在本地执行。搜索用的线长各自采用案例定义的指标，三维结果来自固定材料与边界的封装模型；布后时序和实物降温尚未验证。
