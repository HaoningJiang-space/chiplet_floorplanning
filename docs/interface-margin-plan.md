# 按实际温度计时：芯粒间接口的裕量回收与布局选择（计划，运行前冻结）

## 问题

签核通常让所有器件取同一个最坏温度角（IHP/SKY 慢角 125 °C）。布局决定每条芯粒间网络两端的实际温度，
所以按实际温度计时，有两种可能的价值：

1. **裕量回收**：按实际温度计时，关键网络延迟与签核值相差多少；实际温度超出签核温度范围时，签核本身不覆盖该工作点。
2. **布局选择**：只看长度时，关键网络最短的前沿布局最好；按实际温度计时后，最优布局是否换成另一个更冷的布局。

本步只做模型级上界分析，不建晶体管链；只有当合理参数区间跨过翻转阈值时，才另行计划晶体管级核对。

## 运行前已知（2026-11-15 探测，不作结论）

十例参考前沿共 1340 个布局，在 FV 功率层的 pin 位置取温度：pin 温度 55–149 °C；
Case3/4/5/9/10 有 pin 超过 125 °C；同一网络两端温差最大 13–45 K；每个布局的最长网络 11–88 mm（Manhattan 下界）。

## 模型（冻结，全部为声明假设）

- 每条网络视为加中继的芯粒间连线：延迟 D = (τ·L + D0)·(1 + γ·(T − 25 °C))，
  L 为两端 pin 的 Manhattan 距离，T 为两端 pin 温度的平均值（声明的路径温度代理）。
  中继线延迟随长度线性；γ 统一表示器件与铜线的温度系数。
- 只有比值进入排序，所以用 τ 为单位：D0/τ ∈ {0, 2, 5} mm，γ ∈ {−0.1, 0, 0.1, 0.2, 0.3, 0.4} %/K。
  依据：铜电阻温度系数 0.39 %/K，是连线电阻主导时的上限；器件在名义电压下温度系数接近 0，
  SKY130 tt 1.8 V Liberty 25→100 °C（同工艺同电压）逐格计算：buf_8 中位 −0.07/−0.03 %/K（下降/上升），
  inv_1 中位 +0.12/−0.09 %/K，表格极端处 −0.46 至 +3.4 %/K。γ < 0 表示升温反而变快。
  γ = 0 是对照：此时实际温度代价与签核代价相同，选择必然不变。
- 布局的时序代价 = 所有网络中 D 的最大值（关键网络）；签核代价把所有 T 换成 125 °C。
- 评估集：十例冻结参考前沿（[front-gap0](evidence/front-gap0/)）的全部前沿布局；FV 与 placement 核心相同。

## 输出量与判定（运行前写定）

1. **签核覆盖**：每例前沿中有 pin 超过 125 °C 的布局比例（此时签核角不覆盖实际工作点，与 γ 符号无关）。
2. **回收量**：每个布局关键网络 1 − D(实际)/D(签核)；γ < 0 时为负，即按 125 °C 签核反而偏乐观。报告每例范围与前沿上的差异。
3. **布局选择是否改变**：在每个 (γ, D0/τ) 下，以实际温度代价选出的最优布局 A，与按签核代价（等价于只看长度）
   选出的最优布局 B。若 A ≠ B 且 D_实际(B) − D_实际(A) > 1% × D_实际(B)，记为"改变"；
   1% 是这个线性模型的声明分辨率，低于它记为"不可区分"。
4. 对每例给出使选择改变的 γ 值集合（网格内无则记"网格内不改变"）。

## 运行前估计

探测中每例前沿最长网络的范围相差 1.8–6.8 倍，而关键网络温度变化估计为 10–30 K，
|γ| ≤ 0.4 %/K 时只对应 ≤ 4–12% 的延迟变化。所以预测：多数例子选择不变，只在关键网络长度接近并列时改变；
γ = 0.3 %/K 时回收量约 8–13%（实际 80–100 °C 对 125 °C），布局之间差别小；γ ≤ 0 时无回收；
Case3/4/5/9/10 有部分前沿布局超出签核温度。

## 结果（2026-11-15，eex005，`45b8bd3`，按上述冻结方法执行）

证据：[interface-margin-v1.json](evidence/interface-margin-v1.json)（每例逐布局 pin 最高温、关键网络长度与温度、全部格点判定）。
十例 1340 个前沿布局全部重解，峰温与冻结前沿一致（差 ≤1e-6 K）。

**布局选择：没有任何格点改变。** 10 例 × 18 个 (γ, D0/τ) 格点中，90 个"不变"、90 个"不可区分"、0 个"改变"；
实际温度代价相对签核最优布局的最大优势 0.40%，低于 1% 分辨率。
"不可区分"来自并列：9 例中有 2–13 个前沿布局的关键网络长度完全相同（同一对芯粒、同一距离），
温度只在并列者之间挑选。原因是量级：每例前沿的关键网络长度跨 1.8–6.8 倍，
而关键网络温度在前沿上最多相差 30 K，温度项最多改变 |γ|·ΔT ≤ 0.4 %/K × 30 K ≈ 12%，不足以让更长的布局胜出。

**签核覆盖。** 有 pin 超过 125 °C 的前沿布局比例：Case5 97%、Case9 77%、Case3 23%、Case4 10%、Case10 3%，其余 0。
这些布局按 125 °C 角签核不覆盖实际工作点，与 γ 无关。

**回收量（长度最优布局的关键网络）。** γ = 0.3 %/K 时 −2.5% 至 +12.2%，γ = 0.4 %/K 时 −3.1% 至 +15.1%；
负值出现在关键网络温度超过 125 °C 的 Case3/5/9。关键网络较冷的 Case2/7/8（65–78 °C）回收 11–12%，
92–107 °C 的 Case1/6/10 约 4–6%。γ ≤ 0 时无回收；SKY130 器件在 1.8 V 下的 γ 接近 0，
所以 0.3–0.4 %/K 是连线电阻主导时的上限情形，不是器件的典型值。

**与运行前估计的对照。** 选择不变：符合。回收量 8–13% 的估计只对较冷的例子成立，较热的例子更小或为负。
签核失效例子与预测一致（Case3/4/5/9/10）。

**结论与局限。** 在这个线性中继线模型和关键网络代价下，按实际温度计时不改变前沿上的布局选择；
它的作用是指出签核角不覆盖的布局，以及给出逐布局的裕量回收量。局限：只看最长网络（并列时温度才起作用）；
路径温度取两端平均；γ 统一且与温度无关；没有晶体管级核对。因为合理参数区间内没有翻转，按计划不进入晶体管级核对。
