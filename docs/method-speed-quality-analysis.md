## 单次求解提速的上限（已测，均为原型）

- **按竖直列做块预条件**：迭代 612 → 538，加上建立开销后更慢。不采用。
  原因：收敛慢的是热量经厚铜均热板与散热器横向扩散的全局平滑模态，不是薄层间的竖直耦合。
- **放宽容差**：rtol 1e-6 时迭代约 240 次（rtol 1e-12 时约 430 次），峰温误差约 3e-6 K，能量误差 < 1e-6。求解部分约快 1.8 倍，整体约 1.3 倍。
- **粗网格 32×32**：Case1–4 约快 2.5 倍，排序 Spearman 0.983–0.995，偏差均值 0.2–0.5 K、标准差 0.16–0.66 K；Case9 不快，因为网格要贴合芯粒边界，线条已很密。只适合筛选，不能用于最终判定。

结论：单次求解再优化，整体最多快约 2 倍。数量级的提升要靠算法，即减少无效的热求解，让每次移动都有方向。

## 第一性原理方向

- **线长**：两端网络的总线长是各芯粒对上 Σ|Δ + c| 之和，对位置是凸的分段线性函数。
  - 固定相对位置关系后，最优位置由 LP 精确给出（`TopologyLP`，方法比较 v2 中长度方向 28/29 最优）。
  - 可加：按芯粒对排序断点并做前缀和，增量求值从 O(网络数) 降到 O(log 网络数)；每对芯粒的独立下界给出线长端的最优性差距。
- **热**：T = T_amb + Σ_k p_k·G_k。布局只通过薄的芯粒层材料改变 G，主体热路径与布局无关。
  - 一次分解就能得到全部单位响应（`power_layer_responses`）；由互易性，一次伴随求解就能得到峰值点对各处热源的灵敏度。
  - 由此可以得到峰温对芯粒位置的梯度，在固定相对位置关系内做序列 LP：最小化线长，约束为线性化的芯粒温度 ≤ 上限，每轮用精确 FV 校正。
  - 这样可以替代随机移动，同时提速和提质。
- **待验证的关键**：线性化预测的精度，即平移或伴随梯度对峰温变化的预测误差。
