# 芯粒内部功率不均匀时朝向的热作用：上界筛查（计划，运行前冻结）

## 问题

现有热感知芯粒布局（TAP-2.5D、ATPlace2.5D、DiffChip、MaskPlace2.5D 等）把每颗芯粒当作均匀发热的方块，所以旋转只影响线长。
真实芯粒内部发热不均匀，例如：
- CPU 的核心区与 L3 缓存区；
- GPU 的计算阵列与边缘的接口物理层。

不均匀时，"哪一侧对着邻居"可能成为温度变量，最优布局也可能随之改变。

已有证据：STAMP-2.5D（arXiv 2504.21140，已读全文）把 Ascend910 中 Vitruvian 芯粒换成块级功率图，在 3 个固定布局上重算温度：
- 峰温只略升，3 种布局的排序不变；
- 结论是"平均功率模型足够"。
它只换了一颗芯粒，没有探索朝向，也没有在不均匀功率下比较更多布局。本筛查回答它没回答的部分。

## 方法（冻结）

**功率模板（上界，声明）**
- 计算芯粒（名称前缀 CPU1、CPU2、GPU）沿本地 x 方向分成两半，一半承担比例 f 的功率；
- 判定用 f = 0.8（两半功率密度比 4:1），另报 f = 0.65；
- 其他芯粒（HBM、DRAM、IODie、Analog、MEMS 等）保持均匀。
- 真实大芯粒往往近似对称（如 Zen 的 L3 在中间），所以"整半不对称"是偏大的上界。上界都小，就不需要真实功率图。

**朝向**
- 只比较每颗计算芯粒在当前朝向上再转 0° 或 180°：芯粒占的位置不变，所以布局合法性和线长都不变，只有温度变；
- 90°、270° 会改变非方形芯粒的外形，不纳入。

**计算**
- 温度对各块功率是线性的，而 0°/180° 不改变导热矩阵。所以每个布局只分解一次矩阵，对每颗芯粒的两半各求一个单位响应；
- 任意朝向组合和任意 f 的温度场都由这些响应叠加得到，并与直接求解核对（单元测试）。

**布局**
- 十例冻结前沿，每例按线长排序后均匀取 8 个布局，包括最短与最长；
- 每个布局报告：
  - T_u：均匀功率（f = 0.5）的峰温；
  - T_0：不均匀功率、保持原朝向；
  - T_best、T_worst：对计算芯粒的 0°/180° 做贪心坐标下降（或上升）得到的最低（或最高）峰温。从原朝向出发，逐颗翻转，接受改进，直到没有改进。

**指标（每例，f = 0.8）**
- **朝向收益** = max over 8 个布局 (T_0 − T_best)：在已有布局上只调朝向能降多少；
- **朝向范围** = max (T_worst − T_best)：只报告；
- **布局后悔** = T_best(均匀模型下最冷的布局) − min over 8 个布局 T_best：按均匀模型选出的布局，在不均匀功率下离最好的布局差多少；
- 均匀模型与不均匀模型（T_best）对 8 个布局排序的 Spearman 相关：只报告。

## 判定（运行前写定，f = 0.8）

- **值得校准**：至少 3 例的朝向收益 ≥ 3 K，或布局后悔 ≥ 2 K。下一步用公开的真实芯粒功率图重做；
- **上界也小，停止**：十例的朝向收益都 < 1 K，并且布局后悔都 < 1 K。与 STAMP-2.5D 的结论一致，这个方向停止；
- 其余为"不确定"。因为真实功率图比上界温和，不确定时也倾向停止，并报告原因。

## 运行前估计

- 互热主要经均热板横向传递，它对芯粒内部毫米级的分布有平滑作用。
- 预计相邻、间隙接近 0 的高功耗芯粒对（Case3、Case4、Case5）的朝向收益最大，为 1–4 K；芯粒小而多的例子（Case7、8、10）< 1 K。
- 预测为"不确定"或"停止"。若"值得校准"，说明 STAMP-2.5D 只测一颗芯粒的做法低估了这个现象。

## 局限

- 单一功率模板（上界）；不含芯粒内部的材料差异；不含 90° 旋转与镜像；
- 只在前沿抽样的布局上调整朝向，不重新搜索位置；稳态、单种子。

**判定：值得校准**。4 例朝向收益 ≥ 3 K（Case3、4、5、9）。f = 0.65 时仍有 3 例 ≥ 3 K。

**布局后悔的设计缺陷（运行后发现，如实报告）**：8 个抽样布局中最长的那个在两种模型下都最冷，所以"均匀模型选出的最冷布局"在构造上就几乎总是赢。后悔为 0 不能说明布局与朝向可分。

**事后分析（不在冻结规则内）：朝向主要帮助紧凑布局。** 下表为同一前沿上最短与最长布局的峰温差（"压缩代价"，K），以及朝向收益在两端的值：

| 例 | 均匀 | 不均匀、原朝向 | 不均匀、最优朝向 | 最短布局的朝向收益 | 最长布局的朝向收益 |
| --- | --- | --- | --- | --- | --- |
| Case3 | 31.4 | 38.7 | 22.8 | 16.6 | 0.7 |
| Case4 | 17.7 | 22.4 | 16.6 | 5.8 | 0.0 |
| Case5 | 23.7 | 23.0 | 21.4 | 4.9 | 3.3 |
| Case9 | 24.2 | 24.5 | 22.7 | 3.9 | 2.2 |
| 其余 | — | — | — | ≤ 2.3 | ≤ 2.0 |

紧凑时芯粒彼此贴近，热的一半朝哪里才有影响；拉开后影响消失。所以在 Case3、Case4 中，朝向改变了线长与温度的取舍曲线：
- Case3 的压缩代价在均匀模型下是 31 K，不均匀但不调朝向时是 39 K，调好朝向后是 23 K；
- 其余例子的变化 ≤ 2 K。
效应集中在少数几颗大功率芯粒紧密排列的例子。

**限定**：功率模板是"整半"的上界；只翻转 180°；没有重新搜索位置；每例只抽 8 个布局。

**下一步的关键问题**：真实芯粒的功率分布有多不对称。
- 很多大芯粒近似对称，例如 Zen CCD 的 L3 位于两排核心中间。对称分布下翻转不起作用。
- 校准要先找有公开数据的、明显不对称的芯粒（接口物理层集中在一侧、核心与缓存分居两侧等），再决定是否值得做联合优化。
