## 我们的区别（逐条，并注明哪一条前作最接近）

1. **异构芯粒 + 真实网表 + 中介层尺寸为连续变量，在一个精确的相对位置整数规划里联合求解。**
   - 最接近：Eris（尺寸可变，但同构、对称、离散步长、贪心，无线长）；FAPlace（异构，但尺寸是布局后的包围盒，贪心）。
   - 我们：长宽是连续变量，进入"芯粒右边界 ≤ 中介层宽度"这类线性约束；线长部分在给定相对关系下精确最优，并有整数规划的界。
2. **每类芯粒各自的温度上限，并用精确 FV 硬性验证。**
   - 前作全部是一个全局峰温（Eris、Coskun、TESA、FAPlace）。
   - 我们：GPU、HBM、IO 各自上限；FV 与 ATPlace 的 ATSim 排序一致（Spearman 0.97–1.00）；伴随梯度精修。
3. **成本随连续面积变化，并跨越光罩阈值。**
   - 最接近：Eris（Stow 成本，用 ≤ 50 mm 回避拼接）；Floorplet（成本模型，但外框固定）；MMPack（拼接，但边界固定、无热无成本）。
   - 我们：良率与成本是长宽的函数（Chiplet Actuary / ECO-CHIP 参数）；单片、拼接（曝光场数 k，缝良率 y_s^(k−1)，y_s 为声明的假设并扫描）、超过 3.3 倍光罩换 CoWoS-L 类，作为离散选择进入同一优化。
4. **输出成本—温度—线长的 Pareto 前沿**，而不是单个加权解（Eris、FAPlace、TESA 都是单解或少数点）。
5. **校准与证据**：工业案例按 GPU 85 °C 标定散热；散热强度扫描（相对收益 13–32% 与散热无关）；良率参数在文献范围内的敏感性分析；单种子、冻结计划、失败如实记录。
6. **对比方法**：FAPlace（代码是否公开未查到，否则按论文复现并注明）、ATPlace2.5D（固定尺寸）、TAP-2.5D（需 CPLEX）、"先定尺寸再布局"的分步做法。

## 不新的部分（论文中如实写）

联合定尺寸与布局（Eris、Coskun、FAPlace）；面积相关良率与成本模型（Stow、Chiplet Actuary、Floorplet）；光罩上限（Eris、Coskun）；拼接禁布区（MMPack）；全局温度约束（Eris、FAPlace、TESA）；线长 + 温度 + 面积三目标（FAPlace）。
