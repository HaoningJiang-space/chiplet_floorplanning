## 解读

1. **长度方向 topology_lp 明显领先**：29 个温度上限中 28 个最短；余下 Case4 的 113.55 °C 上限没有任何方法三个种子都达到。中位差 8%，其余方法约 50% 以上。
   它在固定拓扑下精确求最短，长度是它直接优化的量，这一项优势是结构性的。
2. **温度方向 epsilon 与 topology_lp 并列**：中位差 1.49 与 1.52 K，配对 32 : 52 偏向 LP，
   但同一方法跨种子差异达 0–6 K（如 Case3 LP 三种子 0 / 2.16 / 5.19 K），三种子不足以区分二者。
   两者都明显好于 pareto_ls、nsga、annealing 和 random。
3. **参考前沿不是近似最优**：1000 次 FV 的运行在 13/28 个长度上限上比参考前沿更冷
   （Case10 达 4.43 K，参考 3000 次；Case6 1.35 K，参考 6000 次；Case3/5 参考为 12000 次也被超过），在 19/29 个温度上限上更短。
   参考前沿预算随案例递减（12000/6000/3000），所以较大案例上的差距部分来自参考预算本身，不能只解读为方法效率。
   所以 Case3/5/6/7/8/10 上"距离参考前沿的差距"不能当作距离最优的差距；Case1/2/4/9 上没有运行比参考前沿更冷。
4. **耗时**：topology_lp 每种子中位 688 s、最长 6217 s，其余方法 11–22 s，几乎全部花在逐网络 LP 上。
   `d788b20` 的按芯粒对聚合写法最优值相同、快 20–90 倍，之后的实验使用新写法；本比较按冻结代码如实报告。
   random（Case10，约 350 s）与 epsilon（Case1，152/281 s）的少数长耗时原因未查明，可能是共享服务器负载，不作方法属性解读。

## 原因分析（2026-11-15，基于已发表报告与运行记录，无新计算）

1. **跨种子差异有很大一部分来自共同起点。** 每个 (例, 上限) 内，把各方法三种子的温度差减去方法均值后，
   三个种子的共同成分平均解释 41%（中位 39%）的剩余方差；若起点无影响，期望约 17%（12 个自由度中占 2 个）。
   所以 0–6 K 的种子差异主要反映起点集合的好坏，配对比较是必要的，单看中位数会把起点运气算成方法差异。
2. **长度方向 topology_lp 领先是结构性的。** 它对父布局的相对位置和朝向建立 LP，直接求该拓扑下的精确最短，
   再沿热芯粒对分离扫描；其余方法只靠 1–3 步随机合法移动，几千条网络的总长很少被随机移动同时改善。
   各检查点的中位长度差：topology_lp 26%→21%→8%，pareto_ls 84%→61%→49%，random 几乎不动（120%→115%）。
3. **温度方向两者按长度上限分化，而非整体并列。** 最终检查点按上限从紧到松：
   topology_lp 1.34/1.79/1.78 K，epsilon 2.01/1.44/1.37 K。紧上限下 epsilon 的随机移动很难留在上限内，
   LP 一次扫描就给出许多满足上限的短布局；松上限下可行区域大，直接以 FV 降温的 epsilon 更有效。
   epsilon 在 25% 检查点仍落后（最紧上限 5.59 K，此时它的预算正用于这个上限），说明落后不是预算分段造成的。
4. **其余三种通用方法差的原因相同。** pareto_ls、nsga、annealing 都只有随机合法移动，没有长度修复或精确子问题；
   1000 次 FV、每轮 48 个子代约 20–45 轮，温度差只从约 6.5 K 降到 4.2–5.4 K。
   annealing 把两目标加权成单目标，在两个方向都弱于前两者。
5. **参考前沿弱于短运行的原因**：参考前沿用 pareto_ls 类局部搜索（12000/6000/3000 次 FV），
   受第 4 条同一限制；topology_lp 与 epsilon 1000 次即可超过它，所以较大案例上的"差距"偏小估计了真实距离。

由第 3 条，两者的机制互补，这是组合筛查（[计划](lp-epsilon-plan.md)）的依据。
