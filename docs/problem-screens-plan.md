# 新问题的退化筛查：PHY 位置自由度、中介层面积（计划，运行前冻结）

依据：[ICCAD 论文形态](iccad-paper-patterns.md)；两项新颖性调研（合并步骤、新效应，2026-11-16，结论见文末）。用户感兴趣"合并步骤"和"加入新效应"，要求严格扎实。投入大工作量之前，先验证候选问题不退化。

## 筛查 1：PHY 位置自由度能省多少线长（上限）

- **问题**：现有基准中每条线的两端引脚偏移是固定的。若芯粒间接口（PHY）的位置也是决策变量，同样的布局能省多少线长？
- **上限**：PHY 可以放在芯片边缘任意位置、容量不限时，一条线的最短长度就是两颗芯粒外框之间的曼哈顿距离：dx = max(0, |cx_i − cx_j| − (w_i + w_j)/2)，dy 同理，长度为 dx + dy。真实的槽位与容量约束只会让收益更小，所以这是上限。
- **数据**：ATPlace Case1–10，relation_space 种子 2 的前沿（rs-grb-v4），每例按线长均匀取 16 个布局，再加 16 个随机合法布局（种子 1）。温度不变。
- **指标**：每个布局的节省比例 1 − L_box / L_pin；每例报告前沿布局的中位数与最大值。另报前沿最短布局与最凉布局各自的节省比例。
- **判定**：
  - **不退化**：至少 5 例的前沿中位节省 ≥ 10%；
  - **退化**：至少 7 例的前沿中位节省 < 5%，则放弃这个方向；
  - 其余为不确定，需要带槽位约束的完整实验才能判断。

## 筛查 2：中介层面积与温度的折中

- **问题**：中介层面积直接决定成本（CoWoS 面积昂贵、受光罩限制）。面积缩小时最低可达温度上升多少？
- **设定**：ATPlace Case1–10，中介层两边同乘 s ∈ {0.85, 0.92, 1.0, 1.1, 1.25}（面积约 0.72–1.56 倍）；relation_space，种子 1，400 次 FV，间隙 0，Gurobi 120 s，16 个进程，moe-server。采样放不下时按 relation_space 的回退只用整数规划起点；整数规划也无解则记为不可行。
- **指标**：每例每个 s 的前沿最低峰温与最短线长；ΔT_area = 最低峰温(s = 0.85) − 最低峰温(s = 1.0)。
- **判定**：
  - **不退化**：至少 5 例 ΔT_area ≥ 3 K（或 s = 0.85 不可行，说明面积是硬约束）；
  - **退化**：至少 7 例 ΔT_area < 1 K；
  - 其余为不确定。

## 运行前估计

- 筛查 1：ATPlace 的引脚偏移分布在芯粒内部，固定引脚的线长包含了大量"芯粒内部"的距离，节省可能达到 20–50%，大概率不退化。但这只说明线长代理对引脚位置敏感，热上的收益要另外验证。
- 筛查 2：散热扫描显示布局可控温升占 13–32%，面积缩小会挤压这部分。预计中等规模例子 ΔT_area 在 2–8 K。

## 两项新颖性调研的结论（摘要）

- 合并步骤：划分 + 布局最拥挤（P2P-Chiplet、ChipletPart、ISQED 2026、Sharma/Pande）；布局 + PHY/凸点槽位分配在 2.5D 下与精确热的联合未见（最近的是 arXiv 2607.15005，无热；Chiplet3D，3D，只有旋转）；布局 + 中介层面积/桥接 + 热 + 成本部分覆盖（FAPlace 热只作引导；EMIB 2023 无热）。
- 新效应：翘曲 ↔ TIM 热阻双向耦合在布局层面未见（ATMPlace 只单向）；HBM 刷新感知未见但在我们的标定案例中 HBM 远低于门槛，很可能退化；凸点疲劳部分覆盖。
