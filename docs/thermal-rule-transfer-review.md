复核者认为影响结论迁移的首要缺口是散热边界扰动、芯粒间距和布线。为直接回应其意见，回到相同 SHA、本机重新 fetch，限定同一组 Case5 的五个预算内几何、同一对 CPU2_0 和 CPU2_3、同一平均图及 ±60 W 功率转移，在 64 档/8 子步重放 5 和 50 ms。沿用已经定义的顶面换热减半、增加底面换热两种扰动并重放标称条件。同步量出每套坐标原本留有的最小分轴间距。这个检查选的是先前发现的反例，不是额外独立网表。

### 结果

在三种散热边界、两种间距下，5 ms 均选布局 3，50 ms 均选布局 0。表内为较凉布局相对另一布局的峰温优势，两个时长的胜者方向相反。各组还对其余距离合规几何做了全比较。

| 边界（顶面/底面对流系数，W/m²K） | 原几何，5 ms / 50 ms (K) | 100 µm 净间距，5 ms / 50 ms (K) |
| --- | ---: | ---: |
| 标称，2778 / 0 | 0.602 / 2.709 | 0.691 / 2.724 |
| 顶面减半，1389 / 0 | 0.904 / 2.851 | 0.990 / 2.869 |
| 增加底冷，2778 / 2778 | 0.263 / 2.565 | 0.353 / 2.579 |

五个原始布局的最小分轴间距都为零。加入 100 µm 间距后，保留同一载板、朝向和预算；最近几何修复后布局 0、3 的引脚总距离为 170.488、171.269 m。布局 5 的这一次修复为 180.517 m，超过预算，故该组有四个合规候选；其他可能修复尚未穷举。总计 30 个原始和 24 个正间距的几何/边界/时间组合均有时域复算。正间距各组中，胜者的峰温上界还低于次优及其余各布局的下界，最小分离为 0.345 K。这个例子在所试散热条件与正间距下保持排序翻转。封装厂的实际间距和层叠、详细路由、真实活动/测温仍缺独立证据。[原始几何数据](evidence/thermal-rule-transfer/case5-boundaries.json) · [修复坐标、拒绝候选与全部温度](evidence/thermal-rule-transfer/case5-clearance.json)
