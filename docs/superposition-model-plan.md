# 单芯粒 FV 场叠加模型：验证计划（运行前冻结，2026-11-17）

依据：[方法论分析](overall-research-status.md) 2026-11-17 节；[预算复核](proxy-budget-review.md)。
目的：给协同优化找一个与 FV 误差有界、可测的热模型，替换经验拟合的一维距离代理。

## 模型（`placement/superpose.py`）

稳态导热加对流边界是线性问题，T = T_amb + G·P。若忽略"其他芯粒本体改变导热路径"和"载板边界"两项，G 只依赖位移：
- **校准**：对每种芯粒尺寸，把单颗芯粒（1 W）放在加大的载板中心，做一次 FV，取功耗层（dies 层）的温升场 F_s(x, y)。
  - 均热板尺寸保持与实际例子相同，即 max(100, 实际载板长边 + 20) mm；
  - 载板加大到实际长边的 2 倍，使场覆盖任意两芯粒之间的位移；
  - 每例 FV 次数 = 不同尺寸的芯粒种数，与现在的代理相同。
- **预测**：芯粒 i 的峰值 = T_amb + max_{r ∈ die i} Σ_j P_j F_{s_j}(R_j^{-1}(r − c_j))。
  - R_j 为四分之一转角的旋转；
  - r 在芯粒 i 内按 0.5 mm 间距采样，场用双线性插值；
  - 布局峰值 = 各芯粒峰值的最大值。
- **没有拟合参数**；所有误差来自被忽略的两项和网格离散。

## 验证数据（全部已有，不新增布局 FV）

- 验证 2 的同一批布局：7 例 × 40 个（20 个前沿 + 20 个随机），由 `tools/envelope_check.py` 的同一方法重建（欧氏代理复现差 0.0 K），FV 峰温来自 `docs/evidence/physics-v2-proxy.json`。
- 旋转机制例（[第一性原理复核](evidence/first-principles-proxy-3e9238b.json)）：两颗 20 × 4 mm、100 W 芯粒，50 × 40 mm 载板，中心 (15, 20)/(28, 20) mm，朝向 [90, 90] 与 [0, 90]；已存 FV 为 76.52653 / 78.15577 °C。

## 指标（每例，与欧氏代理、轴向包络并列报告）

1. 误差：最大绝对误差、平均偏差、扣除每例平均偏差后的最大残差。
2. 排序：Spearman（全部 / 前沿 / 随机）。
3. **同一线长预算内的选点后悔值**（复核第 1 节的方法）：前沿按线长递增，以第 k 点的线长为上限，在前 k 点中按模型选最低者，取其 FV 与前 k 点 FV 最低值之差，报告对 k 的最大值；随机子集报告全集选点后悔值。
4. 旋转例：模型预测的两布局温差与 FV 温差（1.629 K）之差。

## 通过门槛（运行前写定）

**采用**需同时满足：
- 7 例中每例前沿预算内最大选点后悔值 ≤ 0.5 K；
- 每例扣除平均偏差后的最大残差 ≤ 1.0 K；
- 每例前沿 Spearman ≥ 0.98；
- 旋转例温差误差 ≤ 0.3 K。

**不采用**：任一例预算内后悔值 > 1.0 K，或扣除偏差后的残差 > 2.0 K。

**其余为部分通过**：先查明误差来源，即其他芯粒本体的导热路径、载板边界或网格，再决定是否进入整数规划，不调参凑门槛。

## 运行前估计

远场由均热板主导，叠加应很准。近场由于其他芯粒本体把热导向均热板，会使被加热芯粒的实际温升低于叠加预测，所以预计模型略偏高。
偏高程度在密集例子（Case3、Case9）上最大，可能在 0.5–2 K。预测旋转例能复现大部分温差，因为近场足迹被精确计入。

## 局限

只验证 FV 模型内部的一致性，不涉及实物标定。数据点来自已有前沿和随机采样，不包含协同优化会主动找到的极端紧凑布局；这类布局在进入整数规划后由 FV 认证兜底。

## 结果（2026-11-17，[证据](evidence/superposed-check-v1.json)）：不采用

按冻结门槛判为 **reject**：
- Case5 前沿预算内后悔值 1.78 K > 1.0 K；
- Case3、5、7、9 扣除偏差后残差 2.2–3.4 K > 2.0 K；
- 旋转例温差误差 0.86 K > 0.3 K（模型 2.49 K，FV 1.63 K）。

三种模型并列（前沿预算内最大后悔值 K / 扣除偏差后最大残差 K / 平均偏差 K）：

| 例 | 叠加模型 | 欧氏代理（拟合） | 轴向包络（MILP 实际用） |
|---|---|---|---|
| Case1 | 0.00 / 0.75 / +0.18 | 0.04 / 1.42 / −1.86 | 1.48 / 2.46 / +0.12 |
| Case3 | 0.00 / 2.82 / +0.94 | 0.00 / 4.44 / +0.54 | 2.61 / 4.77 / +3.31 |
| Case5 | 1.78 / 2.28 / +2.22 | 0.51 / 2.00 / +1.03 | 0.39 / 3.01 / +6.01 |
| Case7 | 0.77 / 3.37 / +3.06 | 0.00 / 1.27 / −0.17 | 0.42 / 1.70 / +1.72 |
| Case9 | 0.48 / 2.20 / +1.96 | 0.00 / 1.30 / +0.74 | 2.10 / 2.36 / +8.52 |
| G1 | 0.05 / 0.10 / +0.03 | 0.05 / 0.12 / +0.06 | 0.16 / 0.25 / +0.35 |
| G2 | 0.05 / 0.51 / +0.10 | 0.00 / 2.55 / −0.92 | 0.46 / 2.45 / −0.22 |

**物理解释（由封装材料直接推出）。**
- 在 dies 层，芯粒本体的导热系数为 100 W/mK，周围填充料只有 1.6；microbump 层在芯粒下方约 125，其余为 1.6。
  所以从中介层到均热板的竖向低热阻通道**只存在于芯粒足迹下方**。
- 其他芯粒的本体可以构成额外的竖向散热路径，因此 G 依赖完整布局，不只依赖源与观察点的位移。
  材料差异说明存在这一机制；当前验证没有量化各路径的热流占比，不能据此断言热主要经由其他芯粒排走。
- 叠加模型读的是"那里没有芯粒"时填充料中的温度，这与密集例子中偏高的现象一致
  （Case7 平均 +3.1 K）；尚未独立隔离该机制对全部残差和旋转例 0.86 K 误差的贡献。
- 欧氏代理的衰减是在**有一颗不发热观测芯粒在场**时测的，部分包含了这一效应，所以排序更好。

**对方法的含义。**
1. 在已验证过的模型里，欧氏代理的预算内选点最好：除 Case5 的 0.51 K 外，各例 ≤ 0.05 K。
   轴向包络的大损失（Case3 2.61 K、Case9 2.10 K、Case1 1.48 K）**来自 MILP 中的轴向距离表示**，而不是欧氏代理本身。
2. 三种模型扣除偏差后的残差都在 1–4.8 K，都不能用作硬温限的认证，FV 认证必须保留。
3. 单芯粒场叠加不能替代多体耦合；要更精确，需要显式表示"其他芯粒本体作为散热通道"（例如块级热阻网络），不能只靠平移叠加。

## 2026-11-17 复核：判定完整性与线性叠加的范围

判定函数与 polygon_check 共用冻结 7 例的完整性和欧氏复现检查；缺案例为 `incomplete`，
复现差非有限或超过 1e-6 K 为 `reproduction_mismatch`。旧实现空结果加一个通过的旋转控制
即可得到 adopt。现有 superposed-check-v1 案例完整、复现差全为 0，重算仍为 reject。

不采用的是“删去其他芯粒后所得单源场再平移叠加”的近似，不是线性导热的叠加原理。
固定完整几何的 G 时，`G^-1 (P1 + P2) = G^-1 P1 + G^-1 P2` 仍成立；
用不同几何的 G1、G2 求单源场后相加，通常不等于完整 G 的解。该区别不要求另启校准实验。
