# 单芯粒 FV 场叠加模型：验证计划（运行前冻结，2026-11-17）

依据：[方法论分析](overall-research-status.md) 2026-11-17 节；[预算复核](proxy-budget-review.md)。
目的：给协同优化找一个与 FV 误差有界、可测的热模型，替换经验拟合的一维距离代理。

## 模型（`placement/superpose.py`）

稳态导热加对流边界是线性问题，T = T_amb + G·P。若忽略"其他芯粒本体改变导热路径"和"载板边界"两项，G 只依赖位移：
- **校准**：对每种芯粒尺寸，把单颗芯粒（1 W）放在加大的载板中心，做一次 FV，取功耗层（dies 层）的温升场 F_s(x, y)。
  - 均热板尺寸保持与实际例子相同，即 max(100, 实际载板长边 + 20) mm；
  - 载板加大到实际长边的 2 倍，使场覆盖任意两芯粒之间的位移；
  - 每例 FV 次数 = 不同尺寸的芯粒种数，与现在的代理相同。
- **预测**：芯粒 i 的峰值 = T_amb + max_{r ∈ die i} Σ_j P_j F_{s_j}(R_j^{-1}(r − c_j))。
  - R_j 为四分之一转角的旋转；
  - r 在芯粒 i 内按 0.5 mm 间距采样，场用双线性插值；
  - 布局峰值 = 各芯粒峰值的最大值。
- **没有拟合参数**；所有误差来自被忽略的两项和网格离散。

## 验证数据（全部已有，不新增布局 FV）

- 验证 2 的同一批布局：7 例 × 40 个（20 个前沿 + 20 个随机），由 `tools/envelope_check.py` 的同一方法重建（欧氏代理复现差 0.0 K），FV 峰温来自 `docs/evidence/physics-v2-proxy.json`。
- 旋转机制例（[第一性原理复核](evidence/first-principles-proxy-3e9238b.json)）：两颗 20 × 4 mm、100 W 芯粒，50 × 40 mm 载板，中心 (15, 20)/(28, 20) mm，朝向 [90, 90] 与 [0, 90]；已存 FV 为 76.52653 / 78.15577 °C。

## 指标（每例，与欧氏代理、轴向包络并列报告）

1. 误差：最大绝对误差、平均偏差、扣除每例平均偏差后的最大残差。
2. 排序：Spearman（全部 / 前沿 / 随机）。
3. **同一线长预算内的选点后悔值**（复核第 1 节的方法）：前沿按线长递增，以第 k 点的线长为上限，在前 k 点中按模型选最低者，取其 FV 与前 k 点 FV 最低值之差，报告对 k 的最大值；随机子集报告全集选点后悔值。
4. 旋转例：模型预测的两布局温差与 FV 温差（1.629 K）之差。

## 通过门槛（运行前写定）

**采用**需同时满足：
- 7 例中每例前沿预算内最大选点后悔值 ≤ 0.5 K；
- 每例扣除平均偏差后的最大残差 ≤ 1.0 K；
- 每例前沿 Spearman ≥ 0.98；
- 旋转例温差误差 ≤ 0.3 K。

**不采用**：任一例预算内后悔值 > 1.0 K，或扣除偏差后的残差 > 2.0 K。

**其余为部分通过**：先查明误差来源，即其他芯粒本体的导热路径、载板边界或网格，再决定是否进入整数规划，不调参凑门槛。

## 运行前估计

远场由均热板主导，叠加应很准。近场由于其他芯粒本体把热导向均热板，会使被加热芯粒的实际温升低于叠加预测，所以预计模型略偏高。
偏高程度在密集例子（Case3、Case9）上最大，可能在 0.5–2 K。预测旋转例能复现大部分温差，因为近场足迹被精确计入。

## 局限

只验证 FV 模型内部的一致性，不涉及实物标定。数据点来自已有前沿和随机采样，不包含协同优化会主动找到的极端紧凑布局；这类布局在进入整数规划后由 FV 认证兜底。
