# ATPlace2.5D 原方法作为基线：可行性调查

2026-11-13，只读源码与检查 eex005 环境，未安装或运行。源：`PKU-IDEA/ATPlace_pub` 固定提交 `fe3dbfd`。

## 与本项目设定的差异

| 项目 | ATPlace | 本项目当前设定 | 影响 |
| --- | --- | --- | --- |
| 芯粒间距 | 合法化非重叠约束 `x_i + (w_i+w_j)/2 ≤ x_j`，**间距 0**，可贴边 | 声明的 1 mm 间隙 | ATPlace 输出在 1 mm 域内通常不合法；Case5 在 1 mm 下仅剩零余量的行排列 |
| 互连指标 | HPWL | 两端 pin Manhattan 下界 | 对两端网络二者相同，可直接对比 |
| 热求解 | ATSim（外部可执行，固定提交 `4b4ff81`，有 SHA-256），先训练紧凑热模型再优化 | 自有 FV（scipy） | 双方各自针对自己的模型；公平比较需双模型评价 |
| 封装 | 均热板 W+H、散热器 2(W+H)，对流 0.01 K/W | 均热板 100 mm、散热器 200 mm，对流 0.009 K/W | 绝对温度不可互换 |
| 材料 | 铜占比混合：250/600、10/50、25/45 µm | 同一组常数 | 材料同源 |
| ILP 求解器 | 默认 Gurobi；可设 `pulp`（CBC） | — | 不必依赖 Gurobi 许可证 |

## 建议

1. ATPlace 案例集上的主比较改用源配置的 **0 间隙**，1 mm 间隙作为敏感性变体保留。这同时消除 Case5 的零余量问题；
   但 `tools/bound_routing_screen.py` 的“一箱一芯粒”论证在 0 间隙下不成立，需另行推导。
2. 运行 ATPlace 时使用 `pulp`，新建 Python 3.9 环境（torch 2.0.1 CPU），下载并校验 ATSim。
3. ATPlace 与本项目方法的最终布局都用两套热模型评价：本项目 FV 与 ATSim（ATPlace 的设定）；
   互连用同一 HPWL。只在两套模型下都成立的排序才写成方法优劣。
4. 计算成本包括 ATPlace 的热模型训练与初始化，按论文要求计入。

工作量估计：环境与 ATSim 半天以内；每案例训练加优化为小时级。尚未开始。
